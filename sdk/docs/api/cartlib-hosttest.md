## Overview

Package hosttest is an in-process fake of the cabinet for a cartridge's own `go test`. [New](cartlib-hosttest.md#func-new) installs a [Host](cartlib-hosttest.md#type-host) as the [cartlib.HostABI](cartlib.md#type-hostabi) every cartlib call reaches under the plain Go toolchain; the Host then drives the Game through the same cart_* bodies the wasm exports use, so Init gets a live [cartlib.Setup](cartlib.md#type-setup), the load phase runs, and the quit-key default applies, exactly as on the cabinet:

```text
func TestAppleNeverLandsOnTheSnake(t *testing.T) {
    h := hosttest.New(t)
    h.Rand = []uint64{spawnIdx(32, 32), foodIdx(32, 31)}
    h.Init(game)
    h.AdvancePastSplash()
    h.Input(hosttest.Press(cartlib.SeatP1, cartlib.KeyJoyA)...)
    h.Tick(33_333)
    if h.Pixel(32, 31) != appleColor { ... }
}
```

The fake answers as the cabinet would where a cartridge can observe the difference: RandomU64 and NowMicros follow scripts, storage and the score table persist across the test, the LCD and lamp state are the last values written, sounds and lamp sequences are bookkept, and every call is also logged on the Host's exported fields. Where the cabinet's answer depends on hardware or on the mounted bundle, the fake takes the bare-.wasm answer (no sheet, no listed lamp sequence refused) unless the test scripts it with [Host.MountAssets](cartlib-hosttest.md#func-host-mountassets), [Host.AddCel](cartlib-hosttest.md#func-host-addcel) or [Host.Channels](cartlib-hosttest.md#type-host).

The cabinet runs a cartridge under TinyGo, whose escape analysis differs from the host toolchain's, so [Host.AllocsPerRun](cartlib-hosttest.md#func-host-allocsperrun) is a fast first check on "nothing allocates after Init" and carttest.RequireNoAllocsAfterInit, which reads TinyGo's own -print-allocs report, stays the oracle.

### type Channel

```go fragment
type Channel struct {
	Kind  ChannelKind // how the channel reads
	Value int32       // button state, axis position or pending delta
	Blob  []byte      // payload of a [ChannelBlob]
}
```

Channel is one scripted non-panel input channel. Value answers a button (non-zero is held) or an axis; a delta reports Value once on the next read, then zero. Blob is a blob channel's bytes, whose length is the declared length a bind is checked against.

### type ChannelKind

```go fragment
type ChannelKind uint32
```

ChannelKind is host_input_bind's kind argument, in wire numbering.

```go fragment
const (
	// ChannelButton is a held-or-not button; Value non-zero is held.
	ChannelButton ChannelKind = 0
	// ChannelAxis is a signed position read as Value.
	ChannelAxis ChannelKind = 1

	ChannelDelta ChannelKind = 2

	ChannelBlob ChannelKind = 3
```

### type Host

```go fragment
type Host struct {

	// Rand and Now are the RandomU64 and NowMicros scripts: consumed in
	// order, repeating the last value once exhausted, 0 when empty.
	Rand []uint64
	Now  []uint64 // microseconds, as NowMicros reports them

	// Channels are the non-panel channels this cabinet offers, by full
	// name ("p1.spinner"). Set them before Init.
	Channels map[string]Channel

	// Storage is the cartridge's private key-value store.
	Storage map[string][]byte
	// Scores is the cartridge's top-ten table, highest first, with the
	// cabinet's policy: a score places when positive and either the table
	// has room or it strictly beats the lowest entry; ties rank after
	// existing equal scores.
	Scores []ScoreEntry
	// RecentNames is the per-seat name the player last confirmed and
	// RecentMRU the per-seat newest-first history behind RecentNameAt.
	RecentNames [2]string   // indexed by seat
	RecentMRU   [2][]string // indexed by seat, newest first
	// Lamps is each seat's lamp levels as last written; a fade lands at
	// once. LightsPlaying is the lamp-sequence path on each seat, "" for
	// none; the fake plays every path it is given.
	Lamps         [2]cartlib.LampLevels
	LightsPlaying [2]string // indexed by seat
	// Glyphs is the cartridge's LCD glyph table.
	Glyphs map[rune]cartlib.GlyphRows
	// RawDirections is the last host_set_raw_directions value.
	RawDirections bool

	// Call logs.
	Logs         []LogEntry     // every host_log call
	Sounds       []SoundCall    // play, stop and stop-all calls
	Strategy     []StrategyCall // player-strategy calls
	Exits        int            // Exit calls
	Rejects      int            // RejectKey calls
	StorageReads []string       // key of every StorageRead
	// contains filtered or unexported fields
}
```

Host is the fake. Script fields (Rand, Now, Channels, the cels) are set before the calls that read them; state fields hold the last value the cartridge wrote; call-log fields grow with every call unless [Host.AllocsPerRun](cartlib-hosttest.md#func-host-allocsperrun) has paused them.

#### func New

```go fragment
func New(tb testing.TB) *Host
```

New returns a Host installed as cartlib's host for the rest of the test; the previous host comes back when the test ends.

**Example**

```go
package hosttest_test

import (
	"fmt"
	"testing"

	"github.com/stealthmonkey99/arkade/sdk/cartlib"
	"github.com/stealthmonkey99/arkade/sdk/cartlib/hosttest"
)

var manifest = []byte(`{"abi":1,"slug":"beep","name":"Beep"}`)

type beep struct {
	chime   uint32
	presses int
}

func (g *beep) Manifest() []byte { return manifest }

func (g *beep) Init(s *cartlib.Setup) { g.chime = s.LoadSound("assets/chime.wav") }

func (g *beep) HandleInput(records []cartlib.InputRecord) {
	for _, r := range records {
		if r.IsPress() && r.Key == cartlib.KeyJoyA {
			g.presses++
			cartlib.PlaySound(g.chime, 1)
		}
	}
}

func (g *beep) Update(dtMicros uint64) {
	cartlib.SetText(cartlib.SeatP1, "PRESSES", fmt.Sprint(g.presses))
}

func (g *beep) Render(fb *cartlib.Framebuffer) {
	fb.Clear(0, 0, 0)
	if g.presses > 0 {
		fb.SetPixel(0, 0, 255, 0, 0)
	}
}

// exampleTB stands in for the *testing.T a real test passes to hosttest.New.
type exampleTB struct {
	testing.TB
	cleanups []func()
}

func (e *exampleTB) Helper()          {}
func (e *exampleTB) Cleanup(f func()) { e.cleanups = append(e.cleanups, f) }

func ExampleNew() {
	tb := &exampleTB{}
	defer func() {
		for _, f := range tb.cleanups {
			f()
		}
	}()

	h := hosttest.New(tb) // in a test: hosttest.New(t)
	h.Init(&beep{})
	h.AdvancePastSplash()
	h.Input(hosttest.Press(cartlib.SeatP1, cartlib.KeyJoyA)...)
	h.Tick(33_333)

	line1, line2, _ := h.LCD(cartlib.SeatP1)
	fmt.Println(line1, line2)
	fmt.Println(h.Sounds)
	fmt.Println(h.Pixel(0, 0))
}
```

Output:

```text
PRESSES 1
[{play 1 1}]
{255 0 0 255}
```

#### func (*Host) AllocsPerRun

```go fragment

```

AllocsPerRun is testing.AllocsPerRun with the Host's call logs paused, so the count is the cartridge's own heap allocations plus the fake's fixed bookkeeping, which allocates nothing: use it to pin "no allocation after Init" on host Go.

```text

if n := h.AllocsPerRun(100, func() { h.Tick(33_333) }); n != 0 { ... }
```

A storage write under a new key still allocates in the fake's map, and a first-time sound or channel bind cannot happen after Init anyway.

#### func (*Host) MountAssets

```go fragment
func (h *Host) MountAssets(dir string) error
```

MountAssets serves every sprite sheet under dir/assets the way the cabinet serves a mounted bundle: each .png carrying an arkade sprite envelope becomes loadable by its bundle-relative path ("assets/title.arkadesprite.png"), and each of its cels, anchor included, lifts with Sheet.Cel. A .png without an envelope is skipped, as the cabinet refuses it. Call it before [Host.Init](cartlib-hosttest.md#func-host-init), usually with "." from the cartridge's own directory; a missing assets directory mounts nothing. It is carttest.FakeHost.MountAssets for an in-process test.

It returns an error for a sheet the cabinet would refuse to load: an envelope that does not parse, a cel outside the image or over 64 pixels on a side.
