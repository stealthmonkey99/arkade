## Overview

Package packfile reads the Årkade level pack format and writes the generated Go a cartridge compiles. It runs in a host-side generator, never inside a cartridge, so unlike [github.com/stealthmonkey99/arkade/sdk/levels](levels.md) it may use maps, fmt and unbounded allocation.

### The pack file format

One file holds one pack, named `<name>` plus [ArkadeExt](levels-packfile.md#constants) ([Ext](levels-packfile.md#constants) is also read; [HasExt](levels-packfile.md#func-hasext) accepts either). It is line-oriented ASCII text. A complete file:

```text
// Comments start with // and take the whole line.
pack solo

legend
  #  wall
  \s floor
  .  target
  $  crate
  *  crate-on-target

level L01
  par 1
  p1x 3
  p1y 1
  |#####|
  |#.$ #|
  |#   #|
  |#####|

level "FIRST BOX"
  budget 3
  |#####|
  |#$ .#|
  |#####|
  layer hazard
  |.....|
  |..~..|
  |.....|
```

Leading and trailing whitespace on a line is insignificant. Blank lines and comment lines are dropped before parsing and may appear anywhere, including between grid rows.

Six directives:

- `pack NAME`: exactly once, first. NAME is `[A-Za-z][A-Za-z0-9_-]*` and names the generated variable (see [Emit](levels-packfile.md#func-emit)).
- `legend`: exactly once, after `pack` and before any level. It declares the main legend, the alphabet every level's grid is written in. Each following line is `CHARACTER NAME [VALUE]`: one printable-ASCII character (or `\s` for space, `\\` for backslash), the name for that cell, `[A-Za-z0-9][A-Za-z0-9_-]*`, and an optional parameter (see "Valued legends"). Characters and names must each be unique within a legend, and `|` cannot be a legend character because it delimits grid rows.
- `legend NAME`: an extra legend, also before the first level, for a layer whose cells do not mean terrain. Same entry syntax, with its own characters and names.
- `level NAME`: starts a level. NAME is a bare token, or a quoted Go string literal when it contains spaces (`level "FIRST BOX"`), and is unique within the pack.
- `layer NAME [LEGEND]`: inside a level, after the main grid, starts an additional named grid ([levels.Layer](levels.md#type-layer)). NAME is a bare token, unique within the level. LEGEND names one of the pack's extra legends; without it the layer is written in the main legend.
- `ent KIND X Y [ARG ...]`: one [levels.Record](levels.md#type-record). See "Records and exits".
- `exit DIR TARGET [LOCK ...]`: one [levels.Exit](levels.md#type-exit). See "Records and exits".

A line's first token is a directive if it is one of those words, so they cannot be metadata keys. Otherwise, inside a level, a line beginning with `|` is a grid row and anything else is a metadata entry.

A grid row is `|`, exactly W cell characters, `|`. The delimiters keep an editor that strips trailing whitespace from narrowing a row of spaces. Every character must be in the grid's legend, every row of one grid must be the same width, and the rows of one grid must be contiguous.

A metadata entry is `KEY VALUE`, where KEY is `[A-Za-z][A-Za-z0-9_-]*` and VALUE is the rest of the line, trimmed. The value's type comes from its spelling, and a cartridge reads it back through the matching typed accessor:

```text
par 12            int      lv.Int("par")
coop true         bool     lv.Bool("coop")
tint #d04040      colour   lv.Color("tint")
hint "go left"    string   lv.Str("hint")
hint go left      string   (quotes are only needed for "12", "true", a
                            leading '#', or leading/trailing spaces)
```

A token starting with `#` is a colour and must be exactly six hex digits; any other token beginning with `#` is an error, not a string. Keys must be unique within a level, and `name` is not a valid key because a level's name is the token on its `level` line.

### Records and exits

Records and exits carry data a one-byte cell cannot:

```text
level west-floor
  wing west
  |#######..######|
  ... 14 more rows ...
  exit right west-pod
  exit up corridor-n2 mapwing
  ent terminal 12 48 file1
  ent npc 40 48 guard
  ent patrol 8 52 24 52 40 52
```

`ent KIND X Y [ARG ...]` is one record. KIND is a bare token with a meaning only the cartridge knows. X and Y are non-negative integers up to 65535 with no unit (see [levels.Record](levels.md#type-record)). ARGs are positional values typed by spelling, as metadata is, and are read back through [levels.Args](levels.md#type-args). A route is a record whose arguments alternate x and y ([levels.Args.Point](levels.md#func-args-point)).

`exit DIR TARGET [LOCK ...]` is one edge out of the level. DIR is a bare token the cartridge gives meaning to, unique within the level. TARGET is another level's name, spelled as its `level` line spells it. The parser resolves it, so an exit to a level the pack does not contain is an error with the line number, and [levels.Exit](levels.md#type-exit).Target is an index into [levels.Pack](levels.md#type-pack).Levels. LOCKs are values typed by spelling.

Records and exits keep the order they were written in; metadata is sorted by key.

### Valued legends

A legend entry may carry one value after its name:

```text
legend palette
  r  red    #d04040
  g  grass  #40a040
  .  none

level P01
  |###|
  layer reveal palette
  |rg.|
```

The parameter is typed by spelling like any other value, and a cartridge reads it by ordinal: `lg.Values.Color(lg.Ordinal(c))`.

Every valued entry of one legend must be the same kind, else the parse fails. An entry written without a parameter is [levels.KindNone](levels.md#type-kind) and reads as missing at every type.

### Errors

[Parse](levels-packfile.md#func-parse) reports every problem it finds (up to 20), each as an [Error](levels-packfile.md#type-error) carrying the file and line:

```text
solo.arkadelevels:14: row is 6 cells wide, the grid's first row is 5
solo.arkadelevels:21: 'Q' at column 3 is not in the legend
solo.arkadelevels:30: duplicate level name "L01"
rooms.arkadelevels:88: level "west-floor": `exit right` points at unknown level "west-podd"
```

### In a cartridge

A cartridge's packs live in [AssetsDir](levels-packfile.md#constants) and compile to [GenFile](levels-packfile.md#constants), the levels.Pack literals TinyGo builds in: a cartridge has no filesystem to read a pack from at run time, and static data folds into the wasm at compile time where a parser would cost code size and allocation. The pack file is the source; GenFile is build output, committed like manifest_gen.go, regenerated by every cartridge build and refused by preflight when stale. A cartridge with generation-time checks runs them from its own [GeneratorDir](levels-packfile.md#constants), whose main is [Main](levels-packfile.md#func-main).

### Size

A grid ships as one byte per cell, folded to a single Go string constant by [Emit](levels-packfile.md#func-emit). A packed bitmask would be smaller but is not readable in a diff.

### Envelope front matter

A pack file may begin with one asset envelope, the common name, description, tags and pinned generator that every asset kind carries, as a fenced block of comment lines before `pack`:

```text
// --- arkade ---
// {
//   "arkade": 1,
//   "kind": "levels",
//   "name": "walls",
//   "generator": { "tool": "levellab", "version": "1.0.0" }
// }
// --- arkade ---

pack walls
...
```

[SplitEnvelope](levels-packfile.md#func-splitenvelope) and [FormatEnvelope](levels-packfile.md#func-formatenvelope) find the block's JSON and render one back. [Parse](levels-packfile.md#func-parse) drops the block as ordinary comment lines, so a pack decodes to the same [levels.Pack](levels.md#type-pack) with or without it.

## Constants

```go fragment
const (
	AssetsDir    = "assets"
	GenFile      = "levels_gen.go"
	GeneratorDir = "tools/genlevels"
)
```

The cartridge layout every build and preflight assume. A cartridge's pack files live in AssetsDir beside its sprites and sounds, and compile to GenFile beside its other sources; the packer leaves them out of the .rcart, since nothing reads a pack at run time. Only files ending in [ArkadeExt](levels-packfile.md#constants) or [Ext](levels-packfile.md#constants) count as packs. A cartridge that wants generation-time checks ([Hook](levels-packfile.md#type-hook), [IndexedHook](levels-packfile.md#type-indexedhook), [PackHook](levels-packfile.md#type-packhook)) puts its own generator, whose main calls [Main](levels-packfile.md#func-main), in GeneratorDir; without one, tools/genlevelpack generates with no checks.

```go fragment
const ArkadeExt = ".arkadelevels"
```

ArkadeExt is a pack file's extension, named like the other asset kinds (walls.arkadelevels beside pop.arkadesound.wav). [Render](levels-packfile.md#func-render) and [HasPacks](levels-packfile.md#func-haspacks) read every file in their directory that ends in it or in [Ext](levels-packfile.md#constants).

```go fragment
const EnvelopeFence = "// --- arkade ---"
```

EnvelopeFence is the sentinel line that opens and closes a pack file's optional envelope block. A pack whose first line is exactly this text has it read as the start of an envelope.

```go fragment
const Ext = ".levels"
```

Ext is the alternate pack file extension. Files named with it are read exactly as [ArkadeExt](levels-packfile.md#constants) files are; name a new pack with ArkadeExt.

## Functions

### func Check

```go fragment
func Check(cfg Config, extras ...Extra) error
```

Check renders cfg and its extras exactly as a build would and reports a [*StaleError](levels-packfile.md#type-staleerror) when cfg.Out or any extra's file is missing or differs. It writes nothing. A hook error or an unparseable pack is returned as is.

### func Emit

```go fragment
func Emit(pkg string, files []*File) ([]byte, error)
```

Emit renders parsed packs as the Go source a cartridge compiles: one package-level `levels.Pack` var per pack, gofmt'd and deterministic for the same inputs. See [VarName](levels-packfile.md#func-varname) for the variable's name.

### func Format

```go fragment
func Format(name string, src []byte) ([]byte, error)
```

Format parses src, so an unparseable pack is refused with [Parse](levels-packfile.md#func-parse)'s own errors, and returns it re-rendered in the canonical shape: one blank line before `legend` and before each level, two-space indentation inside a level, legend characters column-aligned, and every comment kept where it was. Formatting an already-canonical pack is a no-op.

### func FormatEnvelope

```go fragment
func FormatEnvelope(envelopeJSON []byte) string
```

FormatEnvelope renders envelopeJSON, one JSON document in any layout, as the fenced comment block [SplitEnvelope](levels-packfile.md#func-splitenvelope) reads back: one `//` line per line of the document between two [EnvelopeFence](levels-packfile.md#constants) lines, then a blank line.

### func HasExt

```go fragment
func HasExt(name string) bool
```

HasExt reports whether name ends in [Ext](levels-packfile.md#constants) or [ArkadeExt](levels-packfile.md#constants).

### func HasGenerator

```go fragment
func HasGenerator(cartDir string) bool
```

HasGenerator reports whether cartDir carries its own level generator in [GeneratorDir](levels-packfile.md#constants).

### func HasPacks

```go fragment
func HasPacks(cartDir string) (bool, error)
```

HasPacks reports whether cartDir's [AssetsDir](levels-packfile.md#constants) holds at least one pack file. A missing directory is not an error: the cartridge simply has no levels.

### func Main

```go fragment
func Main(cfg Config, extras ...Extra)
```

Main is the whole main function of a cartridge's own generator in [GeneratorDir](levels-packfile.md#constants): it fills an empty cfg.Dir, cfg.Out and cfg.Pkg from [CartridgeConfig](levels-packfile.md#func-cartridgeconfig) of the working directory, renders the packs through the hooks, and writes cfg.Out and every extra's file, leaving up-to-date files untouched. Run with -check, it writes nothing and exits 1 when any of them is stale. The build runs it from the cartridge directory before TinyGo.

A hook failure, an unparseable pack, or a stale file under -check prints the error and exits 1, having written nothing.

### func Parse

```go fragment
func Parse(name string, src []byte) (*levels.Pack, error)
```

Parse parses one pack file's bytes. name appears in error messages and is otherwise unused, so callers holding source in memory can pass any label.

On failure the returned error joins every [Error](levels-packfile.md#type-error) found, in line order.

### func SplitEnvelope

```go fragment
func SplitEnvelope(src []byte) (json, body []byte, ok bool)
```

SplitEnvelope reports whether src begins with an envelope block: its first line is exactly [EnvelopeFence](levels-packfile.md#constants), followed by one or more `//` comment lines, closed by a second [EnvelopeFence](levels-packfile.md#constants) line. When it does, json is those comment lines with the leading "//" and one following space stripped, joined with "\n" and left undecoded. body is everything after the closing fence, less one immediately following blank line.

ok is false for anything else, including a truncated or malformed fence. That is not an error: body is then src, unchanged.

### func Sync

```go fragment
func Sync(check bool, outs ...Output) error
```

Sync brings each output's file to its Src. A file already holding exactly Src is not rewritten. With check set it writes nothing and instead returns an error naming every output that is missing or differs.

### func VarName

```go fragment
func VarName(pkg, pack string) string
```

VarName is the identifier Emit gives a pack: the pack's name in camel case plus a "Pack" suffix, so `pack bonus-rooms` becomes bonusRoomsPack. It is exported unless pkg is "main".

## Types

### type Config

```go fragment
type Config struct {
	Dir string // directory holding the pack files
	Out string // path of the generated .go file; Render does not need it
	Pkg string // package clause for the generated file; empty means "main"

	// Hook and IndexedHook are optional and mutually exclusive.
	Hook        Hook        // runs once per level; see [Hook]
	IndexedHook IndexedHook // like Hook, with the level's index; see [IndexedHook]

	// PackHook is optional and independent of the two above. It runs once per
	// pack, after every level of that pack has passed its hook.
	PackHook PackHook
}
```

Config drives [Render](levels-packfile.md#func-render), [Generate](levels-packfile.md#func-generate) and [Check](levels-packfile.md#func-check).

#### func CartridgeConfig

```go fragment
func CartridgeConfig(cartDir string) Config
```

CartridgeConfig is the [Config](levels-packfile.md#type-config) for cartDir under the standard layout, with no hooks: the packs in [AssetsDir](levels-packfile.md#constants) in, [GenFile](levels-packfile.md#constants) out, package main.

### type Error

```go fragment
type Error struct {
	File string // name as passed to [Parse]
	Line int    // 1-based line number
	Msg  string // what is wrong
}
```

Error is one problem at one line of one pack file.

#### func (*Error) Error

```go fragment
func (e *Error) Error() string
```

Error formats as file:line: message.

### type Extra

```go fragment
type Extra func(files []*File) (Output, error)
```

An Extra renders a further generated file from the validated packs, for a generator whose cartridge compiles more than the levels.Pack literals (an id table, a derived attract-mode script). It runs only after every hook has passed.

### type File

```go fragment
type File struct {
	Path string       // file the pack was read from
	Pack *levels.Pack // the parsed pack
}
```

File is one parsed pack file: the pack it declares and the path it was read from. The generated file cites only the path's base name.

#### func Generate

```go fragment
func Generate(cfg Config) ([]*File, error)
```

Generate is [Render](levels-packfile.md#func-render) followed by writing cfg.Out. An up-to-date cfg.Out is left untouched, so its timestamp moves only when its content does. It returns the parsed packs in output order.

#### func ParseFile

```go fragment
func ParseFile(path string) (*File, error)
```

ParseFile reads and parses one pack file.

#### func Render

```go fragment
func Render(cfg Config) ([]*File, []byte, error)
```

Render parses every pack file in cfg.Dir in name order, runs cfg.Hook or cfg.IndexedHook over every level and cfg.PackHook over every pack, and returns the parsed packs with the Go source [Emit](levels-packfile.md#func-emit) makes of them. It writes nothing. cfg.Out is ignored.

Errors from all files and levels are reported together.

### type Hook

```go fragment
type Hook func(lv *levels.Level) ([]levels.Entry, error)
```

A Hook inspects one parsed level at generation time. A returned error fails the generation, and the returned entries are metadata the checker derived, such as a solver's `par`. A returned entry replaces a same-key entry from the pack file.

The level is already decoded, so a Hook uses the same accessors as the cartridge. It runs on the host and may allocate and use maps freely.

### type IndexedHook

```go fragment
type IndexedHook func(i int, lv *levels.Level) ([]levels.Entry, error)
```

An IndexedHook is a [Hook](levels-packfile.md#type-hook) that also receives the level's ordinal position, counting from 0 across the whole run in the pack-then-level order [Generate](levels-packfile.md#func-generate) walks. It suits checks that depend on where a level sits in the sequence.

### type Output

```go fragment
type Output struct {
	Path string // file to write
	Src  []byte // exact contents it must hold
}
```

An Output is one generated file: where it goes and the bytes it must hold.

### type PackHook

```go fragment
type PackHook func(p *levels.Pack) error
```

A PackHook inspects one whole parsed pack at generation time and can only refuse it. It suits checks across levels, such as whether every room is reachable through the exits. A pack has no metadata to derive into, so a check that wants to write something does it per level from a [Hook](levels-packfile.md#type-hook).

### type StaleError

```go fragment
type StaleError struct {
	Files   []string // "no levels_gen.go" or "levels_gen.go differs", one per file
	Sources []string // the pack files they are generated from, as assets/<name>
}
```

StaleError is what [Sync](levels-packfile.md#func-sync), [Check](levels-packfile.md#func-check) and a generator's -check report: the generated files that are missing or no longer what the pack files generate, whether because a pack changed since the last build or because someone edited the generated Go.

#### func (*StaleError) Error

```go fragment
func (e *StaleError) Error() string
```

Error lists the stale files and their sources.
