## Overview

Package input is the cartridge ABI's input vocabulary: the decoded 8-byte input record (docs/CARTRIDGE.md, "Input records"), its key, joystick and flag ordinals, the [Seat](ui-input.md#type-seat) and [Slot](ui-input.md#type-slot) a record carries, and the [Direction](ui-input.md#type-direction) the sdk/ui widgets speak.

sdk/cartlib re-exports every name here (cartlib.InputRecord is [Record](ui-input.md#type-record)), so a cartridge does not need to import this package by name. Nothing here allocates.

const (
	// FlagVirtual marks a keyboard or keyboard-driven virtual stick, as
	// opposed to real HID hardware. A real joystick push emits a KindJoystick
	// record and a non-virtual direction keypress; [Record.PressDir] uses this
	// flag to count the push once.
	FlagVirtual uint8 = 1 << 0
	// FlagShift reports whether shift was held.
	FlagShift uint8 = 1 << 1

## Types

### type Direction

```go fragment
type Direction uint8
```

Direction is a d-pad intent, the navigation vocabulary of the sdk/ui widgets. [DirNone](ui-input.md#type-direction) is the zero value.

```go fragment
const (
	DirNone Direction = iota
	DirUp
	DirDown
	DirLeft
	DirRight
)
```

The Direction values: no direction, then the four d-pad directions.

#### func (Direction) Horizontal

```go fragment
func (d Direction) Horizontal() bool
```

Horizontal reports whether d is [DirLeft](ui-input.md#type-direction) or [DirRight](ui-input.md#type-direction).

#### func (Direction) Vertical

```go fragment
func (d Direction) Vertical() bool
```

Vertical reports whether d is [DirUp](ui-input.md#type-direction) or [DirDown](ui-input.md#type-direction).

### type Record

```go fragment
type Record struct {
	// Kind is KindKeydown, KindKeyup, KindKeypress or KindJoystick.
	Kind uint8
	// Key is one of the Key* ordinals. Meaningless on a KindJoystick record.
	Key uint8
	// Player is the pairing slot: who is player one or two in the game.
	Player Slot
	// Joy is JoyCenter or one of JoyN..JoyNW. Set only on KindJoystick
	// records.
	Joy uint8
	// Source is SourceKeyboard or SourceController.
	Source uint8
	// Physical is the cabinet seat this input came from: which LCD and
	// button-light bank sit in front of this human. It is [SeatNone] for a
	// source with no seat, such as a keyboard, the browser or a microphone.
	// Player is who they are in the game; Physical is where they sit. Address
	// LCDs and lamps by Physical and game logic by Player.
	Physical Seat
	// Index is the controller slot, or [IndexNone] for a source that is not
	// a controller.
	Index uint8
	// Flags is a bitmask of FlagVirtual and FlagShift.
	Flags uint8
}
```

Record is one decoded input record. A cartridge receives a slice of them per tick in Game.HandleInput; the host builds them, so every field holds one of the values documented on it.

#### func (Record) Dir

```go fragment
func (r Record) Dir() Direction
```

Dir is the direction r names, whatever its Kind: an arrow key on a keydown, keyup or keypress record, or a cardinal stick position on a KindJoystick record. Diagonals, the stick's centre and every other key are DirNone. This is the level decode that hold tracking wants; to act once per push use [Record.PressDir](ui-input.md#func-record-pressdir).

#### func (Record) IsPress

```go fragment
func (r Record) IsPress() bool
```

IsPress reports whether r is the canonical "pressed" record, KindKeypress. It is true once per physical press; do not also act on the KindKeydown.

#### func (Record) IsQuit

```go fragment
func (r Record) IsQuit() bool
```

IsQuit reports whether r is about a quit key (KeyQuit, KeyEscape or KeyJoyB, the red button), whatever its Kind. Combine it with [Record.IsPress](ui-input.md#func-record-ispress) to act once per press; a hold-to-confirm also needs the keydown and keyup records.

#### func (Record) PressDir

```go fragment
func (r Record) PressDir() Direction
```

PressDir is the direction r presses, counted once per physical push: a KindJoystick record or a virtual (keyboard) arrow keypress. A real stick also sends a non-virtual arrow keypress for the same push, which is DirNone here. Keydown, keyup, diagonals and the stick's return to centre are DirNone.

#### func (Record) Virtual

```go fragment
func (r Record) Virtual() bool
```

Virtual reports whether r came from a keyboard or a keyboard-driven virtual stick (FlagVirtual) rather than real HID hardware.

### type Seat

```go fragment
type Seat uint8
```

Seat is a physical cabinet position: the LCD, button lamps and controller port in front of one human. Records report it in [Record.Physical](ui-input.md#type-record), and every peripheral call (LCD text, lamps, recent names) takes one.

```go fragment
const (
	// SeatP1 and SeatP2 are the two seats.
	SeatP1 Seat = 0
	SeatP2 Seat = 1
	// SeatBoth addresses both seats' hardware at once. It is an argument to
	// peripheral calls only and never appears in a record. Calls that name
	// one specific seat (recent names, LockPlayerToSeat) treat it as
	// [SeatNone].
	SeatBoth Seat = 0xFE
	// SeatNone is "no seat", what a record from a keyboard, the browser or
	// the microphone carries. Peripheral calls given SeatNone do nothing, so
	// a record's Physical can be passed straight through.
	SeatNone Seat = 0xFF
)
```

The Seat values: the two physical seats, plus the two non-seat sentinels.

#### func SeatOf

```go fragment
func SeatOf(v int) Seat
```

SeatOf converts a zero-based seat index to a Seat: 0 is [SeatP1](ui-input.md#type-seat), 1 is [SeatP2](ui-input.md#type-seat), and every other value, including -1, is [SeatNone](ui-input.md#type-seat). A cartridge that means both seats writes [SeatBoth](ui-input.md#type-seat). Prefer SeatOf to a non-constant Seat(v) conversion, which wraps an out-of-range int to an arbitrary byte.

#### func (Seat) Index

```go fragment
func (s Seat) Index() int
```

Index returns 0 for [SeatP1](ui-input.md#type-seat), 1 for [SeatP2](ui-input.md#type-seat) and -1 for anything else. It is the inverse of [SeatOf](ui-input.md#func-seatof) for a single seat; check the result, or [Seat.Single](ui-input.md#func-seat-single), before indexing a per-seat [2]T array.

#### func (Seat) Other

```go fragment
func (s Seat) Other() Seat
```

Other returns the opposite seat for [SeatP1](ui-input.md#type-seat) or [SeatP2](ui-input.md#type-seat), and s unchanged for anything else.

#### func (Seat) Single

```go fragment
func (s Seat) Single() bool
```

Single reports whether s names exactly one seat ([SeatP1](ui-input.md#type-seat) or [SeatP2](ui-input.md#type-seat)).

### type Slot

```go fragment
type Slot uint8
```

Slot is a pairing slot: whether a record's human is player one or player two in the game, independent of where they sit. See [Record.Player](ui-input.md#type-record).

```go fragment
const (
	// SlotNone is the zero value of an unset Slot. The host never emits it:
	// keyboard and system records read as SlotP1.
	SlotNone Slot = 0
	// SlotP1 is player one.
	SlotP1 Slot = 1
	// SlotP2 is player two.
	SlotP2 Slot = 2
)
```

The Slot values. Slots are one-based, so they do not match [Seat](ui-input.md#type-seat) ordinals.

#### func SlotOf

```go fragment
func SlotOf(v int) Slot
```

SlotOf converts a zero-based player index to a Slot: 0 is [SlotP1](ui-input.md#type-slot), 1 is [SlotP2](ui-input.md#type-slot), and every other value, including -1, is [SlotNone](ui-input.md#type-slot). Slots are one-based, so Slot(v) of a zero-based index is off by one; use SlotOf.

#### func (Slot) Index

```go fragment
func (s Slot) Index() int
```

Index returns 0 for [SlotP1](ui-input.md#type-slot), 1 for [SlotP2](ui-input.md#type-slot) and -1 for anything else. It is the inverse of [SlotOf](ui-input.md#func-slotof) for a real slot; check the result before indexing a per-player [2]T array.
