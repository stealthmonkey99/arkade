## Overview

Package levels holds the cartridge-side shape of a cartridge's authored levels: the Go literals the level generator emits from a text pack file. The pack format and the generator live in the host-side subpackage [github.com/stealthmonkey99/arkade/sdk/levels/packfile](levels-packfile.md); this package parses nothing: the host-only tooling is packfile, and this package is the half that runs in the cartridge.

A level is a grid of single-byte cells, a pack-wide [Legend](levels.md#type-legend) naming each cell character, and open metadata read through typed accessors. Further grids over the same board are named [Layer]s. What a byte cannot carry has its own type: a [Record](levels.md#type-record) is a typed thing at a position, an [Exit](levels.md#type-exit) is an edge to another level in the same pack, and a named [Legend](levels.md#type-legend) can attach a parameter to each cell character. Their arguments, locks and parameters are all [Args](levels.md#type-args).

```go fragment
for y := 0; y < lv.H; y++ {
    for x := 0; x < lv.W; x++ {
        if lv.At(x, y) == '#' {
            drawWall(x, y)
        }
    }
}
par, _ := lv.Int("par")
```

Everything here runs inside the cartridge under TinyGo, so it uses no maps, no imports and no allocation, at load or afterwards. Lookups scan short slices linearly. The generated pack must be composite literals of constants only, with no function calls and no init: a table built by a function is silently absent in the wasm build while host-side tests still pass.

## Types

### type Args

```go fragment
type Args []Value
```

Args is a positional list of [Value]s. Every accessor takes an index and reports ok=false when it is out of range or holds a value of another kind, so a string where a number was expected reads as absent, not as zero.

#### func (Args) Bool

```go fragment
func (a Args) Bool(i int) (value, ok bool)
```

Bool returns argument i as a boolean. The first result is the value, the second says whether there was one.

#### func (Args) Color

```go fragment
func (a Args) Color(i int) (value uint32, ok bool)
```

Color returns argument i as a packed 0xRRGGBB colour.

#### func (Args) Int

```go fragment
func (a Args) Int(i int) (value int, ok bool)
```

Int returns argument i as an integer.

#### func (Args) Point

```go fragment
func (a Args) Point(i int) (x, y int, ok bool)
```

Point returns arguments i and i+1 as an x, y pair; ok is false unless both are integers. A route is a [Record](levels.md#type-record) whose arguments alternate x and y:

```text
for i := 0; ; i += 2 {
    x, y, ok := r.Args.Point(i)
    if !ok {
        break
    }
    ...
}
```

#### func (Args) Str

```go fragment
func (a Args) Str(i int) (value string, ok bool)
```

Str returns argument i as a string.

### type Entry

```go fragment
type Entry struct {
	Key  string // metadata key, unique within a level
	Kind Kind   // which of Int and Str is meaningful
	Int  int    // KindInt's value; KindBool's, as 0 or 1
	Str  string // KindStr's value
}
```

Entry is one metadata key and its value. The generator writes a level's entries sorted by Key.

### type Exit

```go fragment
type Exit struct {
	Dir    string // direction token, unique within a level
	Target int    // index into Pack.Levels
	Locks  Args   // what the doorway asks of the player
}
```

Exit is one edge out of a level into another level of the same pack.

Target is an index into [Pack.Levels](levels.md#type-pack). The parser resolves the level name written in the pack file, so a dangling reference fails the build.

Dir is a token the cartridge gives meaning to, such as "left" or "next", and is unique within a level. Locks are what the doorway asks of the player, such as a quota tier, an ability name or an item.

### type Kind

```go fragment
type Kind uint8
```

Kind says which of an [Entry](levels.md#type-entry)'s or [Value](levels.md#type-value)'s value fields is meaningful. KindInt is the zero value, so a validation hook can return a derived integer as a bare literal such as levels.Entry{Key: "par", Int: n}.

```go fragment
const (
	KindInt   Kind = iota // Entry.Int / Value.Int
	KindStr               // Entry.Str / Value.Str
	KindBool              // Entry.Int / Value.Int, 0 or 1
	KindColor             // Entry.Int / Value.Int, 0xRRGGBB
	KindNone              // no value, as for an unvalued legend entry
)
```

The Kind values.

### type Layer

```go fragment
type Layer struct {
	Name   string // layer name, unique within a level
	Legend string // name of the legend the cells use; "" for the main legend
	W, H   int    // dimensions, in cells
	Cells  string // row-major, W*H bytes
}
```

Layer is an additional named grid over the same level, with its own dimensions (an edge grid is one column wider than the cells it separates).

A layer is written in the pack's main legend unless Legend names another, which is "" for the main legend. [Pack.LayerLegend](levels.md#func-pack-layerlegend) resolves it.

#### func (*Layer) At

```go fragment
func (ly *Layer) At(x, y int) byte
```

At returns the character at (x, y), or 0 outside the layer.

### type Legend

```go fragment
type Legend struct {
	Name   string   // "" for the main legend
	Runes  string   // cell characters; Runes[i] is ordinal i
	Names  []string // declared name per ordinal, parallel to Runes
	Values Args     // per-ordinal parameter; empty when the legend has none
}
```

Legend names the grid characters a pack uses. Runes[i] is cell ordinal i's character and Names[i] is the name the pack file declared for it, in declaration order, so parallel tables (tile colors, sprites) can be indexed by ordinal.

Name is "" for a pack's main legend and the declared name for an extra one ([Pack.Legends](levels.md#type-pack)). Values, when non-empty, holds one [Value](levels.md#type-value) per ordinal, the parameter that entry carries:

```go fragment
rgb, ok := lg.Values.Color(lg.Ordinal(c))
```

An entry written without a parameter has [KindNone](levels.md#type-kind), so it reads as missing at every type.

#### func (*Legend) Ordinal

```go fragment
func (lg *Legend) Ordinal(c byte) int
```

Ordinal returns c's cell ordinal, or -1 if c is not in the legend. It scans Runes linearly.

### type Level

```go fragment
type Level struct {
	Name    string   // level name, unique within a pack
	W, H    int      // main grid dimensions, in cells
	Cells   string   // the main grid, row-major, W*H bytes
	Layers  []Layer  // extra named grids
	Records []Record // typed things, in authored order
	Exits   []Exit   // edges to other levels of the pack
	Meta    []Entry  // metadata, sorted by Key
}
```

Level is one authored level: its main grid, any extra layers, its records and exits, and its metadata.

#### func (*Level) At

```go fragment
func (l *Level) At(x, y int) byte
```

At returns the main grid's character at (x, y), or 0 outside the level. No cell character is treated as solid; a game that wants outside to be wall wraps this.

#### func (*Level) Bool

```go fragment
func (l *Level) Bool(key string) (value, ok bool)
```

Bool returns the boolean metadata value for key. The first result is the value, the second says whether the key was there, with the same wrong-kind-is-missing rule as [Level.Int](levels.md#func-level-int).

#### func (*Level) Color

```go fragment
func (l *Level) Color(key string) (value uint32, ok bool)
```

Color returns the packed 0xRRGGBB metadata value for key, with the same wrong-kind-is-missing rule as [Level.Int](levels.md#func-level-int).

#### func (*Level) Count

```go fragment
func (l *Level) Count(c byte) int
```

Count returns how many main-grid cells hold c.

#### func (*Level) CountRecords

```go fragment
func (l *Level) CountRecords(kind string) int
```

CountRecords returns how many of the level's records have the given kind.

#### func (*Level) Exit

```go fragment
func (l *Level) Exit(dir string) *Exit
```

Exit returns the level's exit in direction dir, or nil if there is none.

#### func (*Level) Find

```go fragment
func (l *Level) Find(c byte) (x, y int, ok bool)
```

Find returns the position of the first c in the main grid, scanning row-major, and whether there was one.

#### func (*Level) Int

```go fragment
func (l *Level) Int(key string) (value int, ok bool)
```

Int returns the integer metadata value for key. ok is false when the key is absent or holds a value of another kind, so a typo in the pack file reads as missing rather than as zero.

#### func (*Level) Layer

```go fragment
func (l *Level) Layer(name string) *Layer
```

Layer returns the named extra grid, or nil if the level has none.

#### func (*Level) Record

```go fragment
func (l *Level) Record(kind string) *Record
```

Record returns the level's first record of kind, or nil. Records keep the order the pack file authored them in, so first means first on the page.

#### func (*Level) Row

```go fragment
func (l *Level) Row(y int) string
```

Row returns grid row y as a W-byte string, or "" outside the level. It slices Cells, so it never copies or allocates.

#### func (*Level) Str

```go fragment
func (l *Level) Str(key string) (value string, ok bool)
```

Str returns the string metadata value for key, with the same wrong-kind-is-missing rule as [Level.Int](levels.md#func-level-int).

### type Pack

```go fragment
type Pack struct {
	Name    string   // pack name
	Legend  Legend   // the main legend
	Legends []Legend // extra named legends
	Levels  []Level  // levels in authored order; Exit.Target indexes this
}
```

Pack is one authored level pack, the contents of one .arkadelevels file. Legend is the main alphabet every level's grid is written in; Legends holds the extra named ones a [Layer](levels.md#type-layer) may use.

**Example**

```go
package levels_test

import (
	"fmt"

	"github.com/stealthmonkey99/arkade/sdk/levels"
)

// demoPack is the shape the level generator emits: composite literals of
// constants only.
var demoPack = levels.Pack{
	Name: "demo",
	Legend: levels.Legend{
		Runes: "# @",
		Names: []string{"wall", "floor", "start"},
	},
	Levels: []levels.Level{{
		Name: "L01", W: 4, H: 3,
		Cells: "####" +
			"#@ #" +
			"####",
		Layers: []levels.Layer{
			{Name: "hazard", W: 4, H: 3, Cells: "...." + "..~." + "...."},
		},
		Records: []levels.Record{
			{Kind: "coin", X: 2, Y: 1, Args: levels.Args{{Kind: levels.KindInt, Int: 10}}},
		},
		Meta: []levels.Entry{{Key: "par", Int: 7}},
	}},
}

func ExamplePack() {
	lv := &demoPack.Levels[0]

	x, y, _ := lv.Find('@')
	fmt.Println("start:", x, y)

	par, _ := lv.Int("par")
	fmt.Println("par:", par)

	hazard := lv.Layer("hazard")
	fmt.Printf("hazard at 2,1: %c\n", hazard.At(2, 1))

	coin := lv.Record("coin")
	value, _ := coin.Args.Int(0)
	fmt.Println("coin at", coin.X, coin.Y, "worth", value)

	_, ok := lv.Str("par")
	fmt.Println("par as a string:", ok)
}
```

Output:

```text
start: 1 1
par: 7
hazard at 2,1: ~
coin at 2 1 worth 10
par as a string: false
```

#### func (*Pack) LayerLegend

```go fragment
func (p *Pack) LayerLegend(ly *Layer) *Legend
```

LayerLegend returns the legend ly's cells are written in. It is never nil for a layer from a parsed pack, since the parser rejects unknown legend names.

#### func (*Pack) LegendNamed

```go fragment
func (p *Pack) LegendNamed(name string) *Legend
```

LegendNamed returns the pack's legend called name: the main legend for "", one of [Pack.Legends](levels.md#type-pack) otherwise, or nil when there is no such legend.

### type Record

```go fragment
type Record struct {
	Kind string // the cartridge's own word for the thing
	X, Y int    // position, in the cartridge's chosen unit
	Args Args   // per-kind properties, in authored order
}
```

Record is one typed thing at one position in a level: a spawn point, an enemy, a pickup, a trigger, a patrol route. Kind is the cartridge's own word for it; this package assigns it no meaning.

X and Y carry no unit: the cartridge decides whether they are cells or pixels, and a validation hook is where range checks belong.

Args are the per-kind properties; a route's waypoints go there too (see [Args.Point](levels.md#func-args-point)).

### type Value

```go fragment
type Value struct {
	Kind Kind   // which of Int and Str is meaningful
	Int  int    // KindInt's value; KindBool's as 0 or 1; KindColor's as 0xRRGGBB
	Str  string // KindStr's value
}
```

Value is one typed value in a positional slot: a [Record](levels.md#type-record) argument, an [Exit](levels.md#type-exit) lock or a [Legend](levels.md#type-legend) entry's parameter. It has the fields of an [Entry](levels.md#type-entry) without the key.
