## Overview

Package fsm is the guest-side screen-state machine: the state variable a cartridge already keeps, with the obligations that hang off every transition made structural. It does not dispatch: `switch machine.State()` stays in the cartridge, guards stay in the code that decides them, and nothing here routes input, updates a sim or draws.

A [Machine](fsm.md#type-machine) is a stack of [State]s at most [MaxDepth](fsm.md#constants) deep; the top is what is on screen. It moves three ways, and the entry hook runs on all of them:

```text
m.Go(s)    replace the top
m.Push(s)  layer over the top; the covered screen stays
m.Pop()    drop the top; the covered screen resumes

m.OnEnter(fn)  fn runs after every arrival, Go/Push/Pop/Reset alike
```

The entry hook is the one place a screen asserts the peripherals it owns, including after a Pop back out from under an overlay.

```go fragment
const (
    stTitle fsm.State = iota
    stPlay
    stOver
    stConfirm
)

var machine fsm.Machine

func Init(s *cartlib.Setup) {
    machine.OnEnter(enterScreen)
    machine.Edges(legalEdges)
    machine.Reset(stTitle)
}

func enterScreen(prev, next fsm.State) {
    switch next {
    case stTitle:
        showTitlePeripherals()
    case stPlay:
        showPlayPeripherals()
    case stOver:
        showGameOverPeripherals()
    case stConfirm:
        showConfirmPeripherals()
    }
}

func update(dtMicros uint64) {
    machine.Tick(dtMicros)
    switch machine.State() {
    case stPlay:
        stepSim(dtMicros)
        if gameOver() {
            machine.Go(stOver)
        }
    case stOver:
        if machine.Elapsed() >= overHoldMicros {
            machine.Go(stTitle)
        }
    }
}
```

A cartridge that adopts the package keeps no parallel state variable: [Machine.State](fsm.md#func-machine-state) is the only copy. Run-wide modifiers that are not screens, such as a solo or versus mode, stay plain package variables.

[Machine.Go](fsm.md#func-machine-go) and [Machine.Push](fsm.md#func-machine-push) take a constant destination, so a walk of the call sites recovers the complete edge set. Do not write `m.Go(nextScreenFor(x))`.

The package obeys the TinyGo cartridge rules: no imports, no interfaces, no goroutines, no panics, and no allocation, including in [Machine.Reset](fsm.md#func-machine-reset). A Machine is a value with no constructor, and hooks are plain top-level funcs. An illegal transition is refused and counted in [Machine.Blocked](fsm.md#func-machine-blocked), never trapped, so a cartridge keeps drawing the screen it is on. A Machine costs 80 bytes on wasm32 and nothing per frame.

Below roughly six states plus a modal, a plain uint8 and a switch is the better choice; nothing in the SDK requires this package.

## Constants

```go fragment
const MaxDepth = 4
```

MaxDepth is how many screens the stack holds at once: one base screen plus MaxDepth-1 overlays. A Push past it is refused.

```go fragment
const MaxStates = 16
```

MaxStates is the largest state set an edge table can describe: one bit per destination in a uint16. A larger machine runs without a table.

## Types

### type IDMachine

```go fragment
type IDMachine struct {
	Machine
	// contains filtered or unexported fields
}
```

IDMachine is [Machine](fsm.md#type-machine) plus one small value: which member of an array of entities this instance is. [Machine.OnEnter](fsm.md#func-machine-onenter)'s hook cannot tell which machine called it, so a hook shared by four jellies or a pool of cars needs an id.

Give each entity its own IDMachine, record its id once, and register one OnEnterID hook shared by all of them:

```go fragment
type jelly struct {
    mode fsm.IDMachine
    fright bool
}
var jellies [4]jelly

var jellyEdges = []uint16{
    jellyChase:  1 << jellyFright,
    jellyFright: 1<<jellyChase | 1<<jellyEaten,
    jellyEaten:  1 << jellyChase,
}

func Init() {
    for i := range jellies {
        jellies[i].mode.SetID(uint8(i))
        jellies[i].mode.OnEnterID(enterJellyMode)
        jellies[i].mode.Edges(jellyEdges)
        jellies[i].mode.Reset(jellyChase)
    }
}

// enterJellyMode is shared by all four jellies; id says which.
func enterJellyMode(id uint8, prev, next fsm.State) {
    switch next {
    case jellyFright:
        jellies[id].fright = true
    case jellyEaten:
        jellies[id].fright = false
    }
}
```

A lone screen machine does not need an id; use IDMachine only when one machine definition is shared by several instances at once.

[IDMachine.Reset](fsm.md#func-idmachine-reset), [IDMachine.Go](fsm.md#func-idmachine-go), [IDMachine.Push](fsm.md#func-idmachine-push) and [IDMachine.Pop](fsm.md#func-idmachine-pop) behave like [Machine](fsm.md#type-machine)'s, with the same refusal rules and [Machine.Blocked](fsm.md#func-machine-blocked) accounting, and then also fire OnEnterID. The other [Machine](fsm.md#type-machine) methods are promoted unchanged, including [Machine.OnEnter](fsm.md#func-machine-onenter), which also still fires.

#### func (*IDMachine) Go

```go fragment
func (m *IDMachine) Go(s State) bool
```

Go replaces the top of the stack with s and fires OnEnterID. See [Machine.Go](fsm.md#func-machine-go); OnEnterID does not fire on a refusal.

#### func (*IDMachine) ID

```go fragment
func (m *IDMachine) ID() uint8
```

ID is the value [IDMachine.SetID](fsm.md#func-idmachine-setid) recorded, or 0 if it was never called.

#### func (*IDMachine) OnEnterID

```go fragment
func (m *IDMachine) OnEnterID(fn func(id uint8, prev, next State))
```

OnEnterID registers the hook that runs after every arrival, like [Machine.OnEnter](fsm.md#func-machine-onenter) but also receiving the id [IDMachine.SetID](fsm.md#func-idmachine-setid) recorded. prev and next mean what they mean there.

Call it once, in Init, with a plain top-level func; a closure allocates. A nil hook does nothing.

#### func (*IDMachine) Pop

```go fragment
func (m *IDMachine) Pop() bool
```

Pop leaves the top screen, re-enters the one beneath, and fires OnEnterID. See [Machine.Pop](fsm.md#func-machine-pop); OnEnterID does not fire on a refusal.

#### func (*IDMachine) Push

```go fragment
func (m *IDMachine) Push(s State) bool
```

Push layers s over the current screen and fires OnEnterID. See [Machine.Push](fsm.md#func-machine-push); OnEnterID does not fire on a refusal.

#### func (*IDMachine) Reset

```go fragment
func (m *IDMachine) Reset(s State)
```

Reset places the machine at s and fires OnEnterID. See [Machine.Reset](fsm.md#func-machine-reset).

#### func (*IDMachine) SetID

```go fragment
func (m *IDMachine) SetID(id uint8)
```

SetID records which entity this instance is. Call it once, in Init, before the first Reset. The zero value's id is 0.

### type Machine

```go fragment
type Machine struct {
	// contains filtered or unexported fields
}
```

Machine holds one screen stack.

The zero value is a usable machine at state 0 with no hooks and no edge table. Init should still call [Machine.Reset](fsm.md#func-machine-reset) so the initial screen's entry hook runs.

**Example**

```go
package fsm_test

import (
	"fmt"

	"github.com/stealthmonkey99/arkade/sdk/fsm"
)

const (
	stTitle fsm.State = iota
	stPlay
	stOver
)

var names = [...]string{stTitle: "title", stPlay: "play", stOver: "over"}

var legalEdges = []uint16{
	stTitle: 1 << stPlay,
	stPlay:  1 << stOver,
	stOver:  1 << stTitle,
}

func enterScreen(prev, next fsm.State) {
	fmt.Println(names[prev], "->", names[next])
}

func ExampleMachine() {
	var m fsm.Machine
	m.OnEnter(enterScreen)
	m.Edges(legalEdges)
	m.Reset(stTitle)

	m.Go(stPlay)
	m.Tick(500_000)
	fmt.Println("elapsed:", m.Elapsed())
	fmt.Println("play -> title allowed:", m.Go(stTitle))
	m.Go(stOver)
	m.Go(stTitle)
	fmt.Println("blocked:", m.Blocked())
}
```

Output:

```text
title -> title
title -> play
elapsed: 500000
play -> title allowed: false
play -> over
over -> title
blocked: 1
```

#### func (*Machine) Blocked

```go fragment
func (m *Machine) Blocked() uint32
```

Blocked is the number of refused operations: undeclared edges, pushes past [MaxDepth](fsm.md#constants), and pops at depth 1. A host-side test can assert it is zero after a scripted journey.

#### func (*Machine) Depth

```go fragment
func (m *Machine) Depth() uint8
```

Depth is the number of screens on the stack: 1 for a bare screen, 2 with one overlay.

#### func (*Machine) Edges

```go fragment
func (m *Machine) Edges(t []uint16)
```

Edges installs the legal-transition table: t[from] with bit `to` set for every declared from->to. It only validates; guards stay in the cartridge.

```go fragment
var legalEdges = []uint16{
    stTitle: 1 << stPlay,
    stPlay:  1<<stOver | 1<<stConfirm,
    stOver:  1 << stTitle,
}
```

An indexed slice literal like that one allocates nothing. A nil table allows every transition. States at or above [MaxStates](fsm.md#constants) are never declared.

#### func (*Machine) Elapsed

```go fragment
func (m *Machine) Elapsed() uint64
```

Elapsed is the dtMicros accumulated since the top screen was entered. It is zeroed by [Machine.Go](fsm.md#func-machine-go) and [Machine.Push](fsm.md#func-machine-push) and continues across [Machine.Pop](fsm.md#func-machine-pop).

#### func (*Machine) Go

```go fragment
func (m *Machine) Go(s State) bool
```

Go replaces the top of the stack with s: exit hook, clock zeroed, entry hook. s must be a constant.

Returns false and does nothing if an edge table is installed and this edge is not in it; the refusal is counted in [Machine.Blocked](fsm.md#func-machine-blocked).

#### func (*Machine) In

```go fragment
func (m *Machine) In(s State) bool
```

In reports whether s is anywhere on the stack, covered screens included.

#### func (*Machine) OnEnter

```go fragment
func (m *Machine) OnEnter(fn func(prev, next State))
```

OnEnter registers the hook that runs after every arrival: [Machine.Go](fsm.md#func-machine-go), [Machine.Push](fsm.md#func-machine-push), [Machine.Pop](fsm.md#func-machine-pop) and [Machine.Reset](fsm.md#func-machine-reset). A screen re-asserts its LCD text and button lamps here, since nothing restores peripherals for it.

prev is the screen departed, covered (Push) or dismissed (Pop). On the first Reset of a fresh machine prev == next.

Call it once, in Init, with a plain top-level func; a closure allocates. A nil hook does nothing.

#### func (*Machine) OnExit

```go fragment
func (m *Machine) OnExit(fn func(cur, next State))
```

OnExit registers the hook that runs before a screen is left by [Machine.Go](fsm.md#func-machine-go) or [Machine.Pop](fsm.md#func-machine-pop). It does not run on [Machine.Push](fsm.md#func-machine-push), since the covered screen is still on the stack, nor on [Machine.Reset](fsm.md#func-machine-reset). Call it once, in Init, with a plain top-level func.

#### func (*Machine) Pop

```go fragment
func (m *Machine) Pop() bool
```

Pop leaves the top screen and re-enters the one beneath, running the entry hook so its peripherals are re-asserted.

The resumed screen's clock continues from where the overlay froze it, so [Machine.Elapsed](fsm.md#func-machine-elapsed) reads as a resume while the hook fires as an arrival.

Returns false, counted in [Machine.Blocked](fsm.md#func-machine-blocked), at depth 1.

#### func (*Machine) Push

```go fragment
func (m *Machine) Push(s State) bool
```

Push layers s over the current screen without leaving it: the covered screen keeps its place on the stack and its clock stops, and [Machine.Pop](fsm.md#func-machine-pop) returns to both.

Returns false, counted in [Machine.Blocked](fsm.md#func-machine-blocked), past [MaxDepth](fsm.md#constants) or on an undeclared edge. s must be a constant.

#### func (*Machine) Reset

```go fragment
func (m *Machine) Reset(s State)
```

Reset places the machine at s with an empty stack and fires the entry hook. Call it once, from Init. The edge table does not police it.

#### func (*Machine) State

```go fragment
func (m *Machine) State() State
```

State is the top of the stack: the screen to dispatch input, update and draw on.

#### func (*Machine) Tick

```go fragment
func (m *Machine) Tick(dtMicros uint64)
```

Tick adds dtMicros to the top screen's clock; covered screens stay frozen. Call it once per Update, before dispatching.

#### func (*Machine) Under

```go fragment
func (m *Machine) Under() State
```

Under is the screen beneath the top, or the top itself at depth 1.

### type State

```go fragment
type State uint8
```

State is a screen. A cartridge declares its own dense enum exactly as it already does, one constant per screen starting at 0:

```text
const (
    stTitle fsm.State = iota
    stPlay
    ...
)
```

State is a defined uint8, so an int variable cannot be passed as a screen.
