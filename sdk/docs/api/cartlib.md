# Package cartlib

```go fragment
import "github.com/stealthmonkey99/arkade/sdk/cartlib"
```

Generated by `sdkdoc` from the package's doc comments, the same text `go doc` and pkg.go.dev show. Edit the Go source, then run `make sdk-docs`.

This page documents the plain-Go (`!tinygo`) build, which a cartridge's `go test` compiles. Only in that build: [CartHandleInput](cartlib.md#func-carthandleinput), [CartInit](cartlib.md#func-cartinit), [CartRender](cartlib.md#func-cartrender), [CartTeardown](cartlib.md#func-cartteardown), [CartUpdate](cartlib.md#func-cartupdate), [HostABI](cartlib.md#type-hostabi), [UseHost](cartlib.md#func-usehost).

## Overview

Package cartlib is the Årkade cartridge SDK for TinyGo: a Go wrapper around the docs/CARTRIDGE.md ABI (see [AbiVersion](cartlib.md#constants)) that supplies every cart_* export a cartridge needs and delegates them to one registered [Game](cartlib.md#type-game). sdk/template is a complete minimal cartridge to copy.

### Registering a Game

A cartridge is a package main that implements [Game](cartlib.md#type-game) and registers one instance with [Run](cartlib.md#func-run) in a package-level initializer:

```go fragment
var game = &myGame{}
var _ = cartlib.Run(game)

func main() {} // runs once during _start; keep it empty
```

The hosts run a cartridge as a WASI reactor: _start runs package initializers and main exactly once at instantiation, before any cart_* export, and preflight refuses a non-empty main or an init function. Guest code therefore executes in two places only: package-level initializers that TinyGo's compile-time interpreter can fold into static data (literals, composite literals, the Run call above), and the cart_* exports the host calls, starting with cart_init ([Game.Init](cartlib.md#type-game)), which is where computed one-time setup belongs.

### Build tags

The host-import declarations and the cart_* exports build only under the tinygo tag. Under the plain Go toolchain every host call goes instead to the [HostABI](cartlib.md#type-hostabi) a test installs with [UseHost](cartlib.md#func-usehost), and panics when none is, so a cartridge's `go test` runs pure game logic as it is and drives the whole Game, Init through Render, against the in-process fake in sdk/cartlib/hosttest. [Game](cartlib.md#type-game), [Framebuffer](cartlib.md#type-framebuffer), the font and input decoding work in both builds.

### Manifest and wasmfix

TinyGo lowers the two-result cart_manifest export through a hidden output pointer, and the tools/wasmfix pass that every SDK build runs after `tinygo build` can rewrite it only when [Game.Manifest](cartlib.md#type-game) returns the same static slice on every call. See [Game.Manifest](cartlib.md#type-game).

### No allocation after Init

A cartridge is built with -gc=leaking, which never frees, so anything allocated per frame leaks for the life of the cabinet process. Every cartlib call usable after Init is allocation-free; the ones that are not (sound and sheet loading, channel binding, glyph definition) are methods of the [Setup](cartlib.md#type-setup) Init receives, which is dead once Init returns. Time comes only from dtMicros or [NowMicros](cartlib.md#func-nowmicros), and randomness only from [RandomU64](cartlib.md#func-randomu64); goroutines are not available.

## Constants

```go fragment
const (
	P1 = "p1."
	P2 = "p2."
)
```

P1 and P2 are the seat prefixes every channel name begins with; there is no seatless channel. `cartlib.P1 + cartlib.ChanA` is a constant.

```go fragment
	ChanA    = "a"
	ChanB    = "b"

	ChanD    = "d"
	ChanAux1 = "aux1"

	ChanL1     = "l1"

	ChanStart  = "start"
	ChanTurbo  = "turbo"
	ChanClear  = "clear"
	ChanHome   = "home"
	ChanEnter  = "enter"
)
```

Standard channel names, joined to [P1](cartlib.md#constants) or [P2](cartlib.md#constants). [ChanJoyX](cartlib.md#constants) and [ChanJoyY](cartlib.md#constants) read the stick as axes of -1, 0 or +1 (the cabinet's stick is an eight-way switch), and [ChanJoyNorth](cartlib.md#constants) and its neighbours read the same stick as four buttons. [ChanA](cartlib.md#constants) through [ChanAux2](cartlib.md#constants) are the six arcade buttons the lamp calls address. The rest exist only on controllers, so binding one fails on a plain cabinet.

```go fragment

```

MaxBoundChannels is how many channels one cartridge may bind, and MaxBlobBytes the largest blob a channel may carry. A bind past MaxBoundChannels fails.


FBWidth and FBHeight are the LED matrix's size in pixels, the only size either host uses; cart_init's (cols, rows) always carry them, which is why [Game.Init](cartlib.md#type-game) does not pass them on.

```go fragment
const (
```
```go fragment
	MaxStorageKeyLen   = 256
	MaxStorageValueLen = 1 << 16
)
```

MaxStorageKeyLen and MaxStorageValueLen are the hosts' caps on a storage key and value, in bytes. A write over either is dropped whole; see [StorageWrite](cartlib.md#func-storagewrite).

```go fragment
const AbiVersion uint32 = 1
```

AbiVersion is the docs/CARTRIDGE.md ABI version cartlib implements and cart_abi_version reports. A host refuses a cartridge whose version it does not support, before cart_init runs.

```go fragment
const CheatSteps = 8
```

CheatSteps is the length of the direction sequence.

```go fragment
const IndexNone = input.IndexNone
```

IndexNone is [InputRecord](cartlib.md#type-inputrecord).Index for a source that is not a controller.

```go fragment
const LampLevelMax = 15
```

LampLevelMax is the brightest lamp level. Levels run 0 (dark) to LampLevelMax; [SetButtonLights](cartlib.md#func-setbuttonlights) and [SetLights](cartlib.md#func-setlights) write LampLevelMax and 0. The cabinet's brightness setting scales every level afterwards.

```go fragment
const MaxCartGlyphs = 32
```

MaxCartGlyphs is how many distinct runes one cartridge may define. It caps the table, not what one screen can show; see [Setup.DefineLCDGlyph](cartlib.md#func-setup-definelcdglyph) for the eight-glyph screen budget.

```go fragment
const MaxNameLen = 64
```

MaxNameLen is the host's cap on a submitted name, in bytes.

```go fragment
const MinSplashMicros uint64 = 500_000
```

MinSplashMicros is the minimum load-phase duration, in microseconds: the splash or [Loader](cartlib.md#type-loader) frame shows for at least this long before the first Update. The phase is timed on dtMicros alone, so both hosts draw the same frames.

## Functions

### func AppendUint

```go fragment
func AppendUint(buf []byte, pos int, v uint32) int
```

AppendUint writes v in decimal into buf starting at pos and returns the index just past the last digit written, for building [SetTextBytes](cartlib.md#func-settextbytes) lines in a package-level buffer without allocating. When fewer than [NumDigits](cartlib.md#func-numdigits)(v) bytes remain it keeps v's lowest digits that fit, so 12345 written with two bytes left is "45"; with none left, or pos past the end, it writes nothing and returns pos. pos must not be negative. Allocation-free; callable in any phase.

### func CartHandleInput

```go fragment
func CartHandleInput(wire []byte)
```

CartHandleInput is cart_handle_input for one batch of 8-byte records, as the host would write them into cart_alloc's buffer: it decodes them and applies the quit-key default before [Game.HandleInput](cartlib.md#type-game). A batch longer than the buffer is truncated, as on the cabinet.

### func CartInit

```go fragment
func CartInit()
```

CartInit is the cart_init body for a host-Go harness: it runs [Game.Init](cartlib.md#type-game) with the live [Setup](cartlib.md#type-setup) and starts the load phase. It also resets the instance state a fresh cartridge starts with (the load phase, the cheat taint), so one test binary can boot the Game more than once. sdk/cartlib/hosttest drives the Cart* functions; a cartridge test should not need to call them itself.

### func CartRender

```go fragment
func CartRender()
```

CartRender is cart_render: it draws the splash or [Loader](cartlib.md#type-loader) frame during the load phase and [Game.Render](cartlib.md#type-game) after it, then blits the frame.

### func CartTeardown

```go fragment
func CartTeardown()
```

CartTeardown is cart_teardown: it runs [Teardowner.Teardown](cartlib.md#type-teardowner) when the Game implements it.

### func CartUpdate

```go fragment
func CartUpdate(dtMicros uint64)
```

CartUpdate is cart_update: it advances the load phase, and calls [Game.Update](cartlib.md#type-game) only once the load phase is over.

### func CheatTainted

```go fragment
func CheatTainted() bool
```

CheatTainted reports whether this cartridge instance has been marked as cheated, by a completed [CheatCode](cartlib.md#type-cheatcode) or by [MarkCheated](cartlib.md#func-markcheated). While it is true, [ScoreSubmit](cartlib.md#func-scoresubmit), [ScoreQualifies](cartlib.md#func-scorequalifies), [ScoreRank](cartlib.md#func-scorerank) and [NoteRecentName](cartlib.md#func-noterecentname) refuse without calling the host; the score reads still work. Nothing clears it: the next launch from the shell starts a fresh instance. Read it to show the player that this session cannot post a score.

### func DecodeInputRecordsInto

```go fragment
func DecodeInputRecordsInto(buf []byte, out []InputRecord) int
```

DecodeInputRecordsInto decodes buf's whole 8-byte records into out and returns how many it wrote, min(len(buf)/8, len(out)); trailing bytes are ignored. Allocation-free.

### func DispatchAttract

```go fragment
func DispatchAttract(dtMicros uint64)
```

DispatchAttract calls the registered Game's [Attractor.Attract](cartlib.md#type-attractor) and sends the frame to the host. It is the body of a cartridge's cart_attract export (see [Attractor](cartlib.md#type-attractor)) and does nothing if the Game is not an Attractor.

### func DrawText

```go fragment
func DrawText(fb *Framebuffer, x, y int, s string, scale int, r, g, b byte)
```

DrawText draws s in cartlib's 3x5 font into fb, top-left at (x, y), each pixel scaled to scale x scale, opaque in (r, g, b). The font covers uppercase A-Z, 0-9, '-' and '?'; any other byte, lowercase included, draws as a blank cell. Pixels outside the frame are clipped. Allocation-free.

### func DrawUint

```go fragment
func DrawUint(fb *Framebuffer, x, y int, v uint32, scale int, r, g, b byte)
```

DrawUint draws v in decimal into fb as [DrawText](cartlib.md#func-drawtext) would draw its digits. Allocation-free.

### func Exit

```go fragment
func Exit()
```

Exit requests this cartridge's unload, back to the shell on the cabinet. The engine applies it between ticks, so it is safe from HandleInput, Update or Render. Unless the Game implements [QuitOwner](cartlib.md#type-quitowner), cartlib calls Exit for every quit-key press.

### func FadeLamps

```go fragment
func FadeLamps(seat Seat, mask ButtonMask, level uint8, fadeMs int)
```

FadeLamps ramps the lamps in mask to level over fadeMs milliseconds, leaving every other lamp's level and fade alone. level is 0..[LampLevelMax](cartlib.md#constants) and is truncated to four bits. It is [SetLampLevels](cartlib.md#func-setlamplevels) with one level for every touched lamp, and shares its seat, fade and sequence-stop rules; an empty mask is a complete no-op.

### func LockPlayerStrategy

```go fragment
func LockPlayerStrategy()
```

LockPlayerStrategy enforces the current strategy, committing to the controller that adopted the game. Call it when play starts.

### func LockPlayerToSeat

```go fragment
func LockPlayerToSeat(seat Seat)
```

LockPlayerToSeat locks the current one-player strategy to a physical seat: the display rotates toward it and input gates to it, whichever controller pressed first. A no-op unless the active strategy is one-player, and for SeatBoth or SeatNone.

### func Log

```go fragment
func Log(level LogLevel, msg string)
```

Log sends msg to the host's log at the given [LogLevel](cartlib.md#type-loglevel). Valid in any phase.

### func MarkCheated

```go fragment
func MarkCheated()
```

MarkCheated taints the session as [CheatCode](cartlib.md#type-cheatcode) does, for a debug affordance other than the shared combo. The taint is one-way.

### func NoteRecentName

```go fragment
func NoteRecentName(seat Seat, name string)
```

NoteRecentName records name as the one the player at seat just confirmed, feeding both [RecentName](cartlib.md#func-recentname) and [RecentNameAt](cartlib.md#func-recentnameat). Call it alongside [ScoreSubmit](cartlib.md#func-scoresubmit), only once the player has confirmed the name. The host trims surrounding blanks and ignores an empty name; SeatBoth and SeatNone do nothing, and so does every call once [CheatTainted](cartlib.md#func-cheattainted) is true.

### func NowMicros

```go fragment
func NowMicros() uint64
```

NowMicros returns the engine clock in microseconds, never wall time, so a replay reads the same values. Prefer accumulating [Game.Update](cartlib.md#type-game)'s dtMicros; use NowMicros only where an absolute timestamp is needed, such as comparing against a stored one.

### func NumDigits

```go fragment
func NumDigits(v uint32) int
```

NumDigits returns the number of decimal digits in v, which is how many characters [DrawUint](cartlib.md#func-drawuint) draws.

### func PackLampLevels

```go fragment
func PackLampLevels(levels LampLevels) uint32
```

PackLampLevels packs six levels into host_set_lamp_levels' wire form: lamp i in bits 4i..4i+3, bits 24..31 zero. Only the low four bits of each level survive, so a level above [LampLevelMax](cartlib.md#constants) wraps rather than clamps. [SetLampLevels](cartlib.md#func-setlamplevels) and [FadeLamps](cartlib.md#func-fadelamps) call it for you; it is exported for cartridge tests.

### func PlayLights

```go fragment
func PlayLights(path string, seat Seat, loop LightsLoop) bool
```

PlayLights starts the lamp sequence at a bundle-relative path, which must be one the manifest lists under assets.lights (docs/ASSETS.md, "Lamp sequences"). The host plays it on the engine clock. PlayLights reports whether anything is now playing: false for an unlisted path, an invalid loop, [SeatNone](cartlib.md#constants), or a sequence with no frames for the seat asked for, and the host logs why.

seat is one seat, or [SeatBoth](cartlib.md#constants) for both seats as the file says. A frame writes only the seats it names, so a one-seat cue played at SeatBoth leaves the other seat alone. Valid in any phase and allocation-free for a constant path. [SetButtonLights](cartlib.md#func-setbuttonlights), [SetLights](cartlib.md#func-setlights) or a [SetLampLevels](cartlib.md#func-setlamplevels) that touches a lamp on the seat stops the sequence.

### func PlaySound

```go fragment
func PlaySound(id uint32, loops LoopCount)
```

PlaySound plays the sound loaded by [Setup.LoadSound](cartlib.md#func-setup-loadsound) as id, loops times in total. An unknown handle, including 0, is a silent no-op.

**Example**

```go
package cartlib_test

import (
	"fmt"
	"testing"

	"github.com/stealthmonkey99/arkade/sdk/cartlib"
	"github.com/stealthmonkey99/arkade/sdk/cartlib/hosttest"
)

// playSoundTB stands in for the *testing.T a real test passes to hosttest.New.
type playSoundTB struct {
	testing.TB
	cleanups []func()
}

func (e *playSoundTB) Helper()          {}
func (e *playSoundTB) Cleanup(f func()) { e.cleanups = append(e.cleanups, f) }

type playSoundGame struct {
	chime uint32
}

var playSoundManifest = []byte(`{"abi":1,"slug":"chimes","name":"chimes"}`)

func (g *playSoundGame) Manifest() []byte { return playSoundManifest }

func (g *playSoundGame) HandleInput(records []cartlib.InputRecord) {}

func (g *playSoundGame) Init(s *cartlib.Setup) {
	g.chime = s.LoadSound("assets/chime.wav")
}

func (g *playSoundGame) Update(dtMicros uint64) {
	cartlib.PlaySound(g.chime, 2)
}

func (g *playSoundGame) Render(fb *cartlib.Framebuffer) { fb.Clear(0, 0, 0) }

func ExamplePlaySound() {
	tb := &playSoundTB{}
	defer func() {
		for _, f := range tb.cleanups {
			f()
		}
	}()

	h := hosttest.New(tb) // in a test: hosttest.New(t)
	g := &playSoundGame{}
	h.Init(g)
	h.AdvancePastSplash()
	h.Tick(16_667)

	for _, c := range h.Sounds {
		fmt.Printf("%s id=%d loops=%d\n", c.Op, c.ID, c.Loops)
	}
	fmt.Println("playing:", h.Playing(g.chime))
}
```

Output:

```text
play id=1 loops=2
playing: true
```

### func PopPlayerStrategy

```go fragment
func PopPlayerStrategy()
```

PopPlayerStrategy removes the strategy this cartridge most recently pushed. The engine pops whatever a cartridge leaves pushed when it unloads.

### func PushPlayerStrategy

```go fragment
func PushPlayerStrategy(kind StrategyKind)
```

PushPlayerStrategy activates a player strategy, which decides whose input reaches [Game.HandleInput](cartlib.md#type-game) and, for [StrategyOnePlayerSolo](cartlib.md#type-strategykind), rotates the display toward that player. A pushed strategy stays permissive until [LockPlayerStrategy](cartlib.md#func-lockplayerstrategy): push on the title screen, lock when play begins.

Both hosts gate and rotate the same way, but neither gates a keyboard record, so a game must not rely on a strategy for correctness: a two-player game still demuxes on each record's Player itself.

### func RandomU64

```go fragment
func RandomU64() uint64
```

RandomU64 returns the next value from the engine-seeded RNG. It is a cartridge's only permitted source of randomness: any other source breaks replay determinism and golden tests.

### func RecentName

```go fragment
func RecentName(seat Seat, buf []byte) (name []byte, ok bool)
```

RecentName returns the name last noted for seat ([NoteRecentName](cartlib.md#func-noterecentname)) within the past hour, across all games, for prefilling a name-entry screen. ok is false when there is none.

seat is the physical seat (a record's Physical), not the pairing slot; SeatBoth and SeatNone return ok=false. buf is caller-owned scratch of at least [MaxNameLen](cartlib.md#constants) bytes and name is a view into it, valid until buf is next written. For the seat's non-expiring history use [RecentNameAt](cartlib.md#func-recentnameat) or [RecentNames](cartlib.md#func-recentnames).

### func RecentNameAt

```go fragment
func RecentNameAt(seat Seat, index int, buf []byte) (name []byte, ok bool)
```

RecentNameAt returns the index-th name in seat's most-recently-used list, index 0 being the newest, or ok=false once index runs past the end. Unlike [RecentName](cartlib.md#func-recentname) the list never expires and survives cabinet restarts. seat, buf and the returned view follow RecentName's rules.

### func RecentNames

```go fragment
func RecentNames(seat Seat) []string
```

RecentNames returns up to five distinct names to offer a player about to enter one, best guess first, in the shape ui.NameEntry.SetRecents takes. seat is the physical seat at the controls; SeatBoth and SeatNone read as SeatP1. The list draws, in order, on seat's MRU list ([RecentNameAt](cartlib.md#func-recentnameat)), the other seat's MRU list, then this cartridge's score table from the top, dropping blanks and duplicates.

Allocation-free: the slice and its strings alias package-level arrays and are valid only until the next call.

### func RejectKey

```go fragment
func RejectKey()
```

RejectKey rings the cabinet's "that key does nothing here" bell. A no-op on hosts with no bell, such as the browser.

### func Run

```go fragment
func Run(game Game) int
```

Run registers game as the cartridge's implementation and returns 0, so it fits a `var _ =` statement. Call it exactly once, as a package-level initializer:

```go fragment
var game = &myGame{}
var _ = cartlib.Run(game)

func main() {}
```

The hosts run _start once at instantiation, before any cart_* export, so the initializer runs then and the TinyGo compiler folds it into static data. main must stay empty: preflight refuses a non-empty main or an init function, and a Run called from main would run too late to be relied on. Computed setup belongs in [Game.Init](cartlib.md#type-game).

**Example**

```go
package cartlib_test

import (
	"fmt"
	"testing"

	"github.com/stealthmonkey99/arkade/sdk/cartlib"
	"github.com/stealthmonkey99/arkade/sdk/cartlib/hosttest"
)

// runTB stands in for the *testing.T a real test passes to hosttest.New.
type runTB struct {
	testing.TB
	cleanups []func()
}

func (e *runTB) Helper()          {}
func (e *runTB) Cleanup(f func()) { e.cleanups = append(e.cleanups, f) }

type runGame struct {
	updates int
}

var runManifest = []byte(`{"abi":1,"slug":"counter","name":"counter"}`)

func (g *runGame) Manifest() []byte { return runManifest }

func (g *runGame) HandleInput(records []cartlib.InputRecord) {}

func (g *runGame) Init(s *cartlib.Setup) {}

func (g *runGame) Update(dtMicros uint64) { g.updates++ }

func (g *runGame) Render(fb *cartlib.Framebuffer) {
	fb.Clear(0, 0, 0)
	cartlib.DrawUint(fb, 1, 1, uint32(g.updates), 1, 255, 255, 255)
}

var runCart = &runGame{}
var _ = cartlib.Run(runCart)

func ExampleRun() {
	tb := &runTB{}
	defer func() {
		for _, f := range tb.cleanups {
			f()
		}
	}()

	h := hosttest.New(tb) // in a test: hosttest.New(t)
	h.Init(runCart)
	h.AdvancePastSplash()
	h.Tick(16_667)
	h.Tick(16_667)

	fmt.Println("updates:", runCart.updates)
	fmt.Println("digit drawn:", h.Pixel(1, 1) != cartlib.Color{A: 255})
}
```

Output:

```text
updates: 2
digit drawn: true
```

### func ScoreQualifies

```go fragment
func ScoreQualifies(score int) bool
```

ScoreQualifies reports whether score would place, by [ScoreSubmit](cartlib.md#func-scoresubmit)'s rule. Check it before offering name entry. Always false once [CheatTainted](cartlib.md#func-cheattainted) is true.

### func ScoreRank

```go fragment
func ScoreRank(score int) int
```

ScoreRank returns the 1-based rank score would take now, or 0 if it would not place, without writing anything. Always 0 once [CheatTainted](cartlib.md#func-cheattainted) is true.

### func ScoreRead

```go fragment
func ScoreRead(rank int, buf []byte) (score int, name []byte, ok bool)
```

ScoreRead returns the entry at a 1-based rank. ok is false past the end of the table, so a caller walks it without a length check:

```text
for r := 1; ; r++ {
    score, name, ok := cartlib.ScoreRead(r, buf[:])
    if !ok { break }
    ...
}
```

buf is caller-owned scratch of at least 8+[MaxNameLen] bytes, and name is a view into it, valid until buf is next written; copy it to keep it. Allocation-free, and unaffected by [CheatTainted](cartlib.md#func-cheattainted).

### func ScoreSubmit

```go fragment
func ScoreSubmit(score int, name string) int
```

ScoreSubmit records a finished run in the cartridge's top-10 table and returns its 1-based rank, or 0 if the score did not place and nothing was written. A score places when it is positive and either the table has room or it strictly beats the lowest entry; a tie with 10th place does not. The table is private to the calling cartridge, and is what the shell and attract mode show, so prefer it to [StorageWrite](cartlib.md#func-storagewrite) for high scores.

Returns 0 without calling the host once [CheatTainted](cartlib.md#func-cheattainted) is true.

### func SetButtonLights

```go fragment
func SetButtonLights(seat Seat, mask ButtonMask, only bool)
```

SetButtonLights turns on the lamps in mask on seat, or on both seats with [SeatBoth](cartlib.md#constants). With only true every lamp outside mask turns off; with only false they keep their state. [SeatNone](cartlib.md#constants) does nothing. The call stops any lamp sequence playing on the seats it addresses (see [PlayLights](cartlib.md#func-playlights)).

### func SetLampLevels

```go fragment
func SetLampLevels(seat Seat, levels LampLevels, touch ButtonMask, fadeMs int)
```

SetLampLevels sets per-lamp brightness on seat, or both seats with [SeatBoth](cartlib.md#constants), optionally as a cross-fade. [SeatNone](cartlib.md#constants) does nothing.

touch names the lamps this call addresses: a lamp outside touch keeps its level and any fade running on it. touch == 0 is a complete no-op, with no write and no sequence stop. Otherwise the call stops any lamp sequence playing on the seats it addresses.

fadeMs is milliseconds: 0 or negative writes instantly, and the host clamps it to 10000. A fade ramps each touched lamp linearly from its current level to the target on the engine clock, so a replay writes the same lamps on the same ticks. A later [SetButtonLights](cartlib.md#func-setbuttonlights), [SetLights](cartlib.md#func-setlights), SetLampLevels or sequence frame touching a lamp cancels its fade.

Allocation-free. Call it from Init, HandleInput or Update.

### func SetLights

```go fragment
func SetLights(seat Seat, on bool)
```

SetLights turns all six of seat's lamps on or off, or both seats' with [SeatBoth](cartlib.md#constants). [SeatNone](cartlib.md#constants) does nothing. Like [SetButtonLights](cartlib.md#func-setbuttonlights), it stops any lamp sequence playing on the seats it addresses.

### func SetRawDirections

```go fragment
func SetRawDirections(enabled bool)
```

SetRawDirections overrides the manifest's rawDirections flag for the running instance. With true, directions arrive as pushed, without the cabinet's seat-mount and display-orientation remap; with false the remap applies. An egocentric game typically enables it for play and disables it on every path back to a menu. The override ends when the cartridge is switched away from or unloads, so a fresh instance starts from the manifest. The browser host remaps, and honors this override, the same way.

### func SetText

```go fragment
func SetText(seat Seat, line1, line2 string)
```

SetText sets the two 16-character LCD lines in front of seat, or in front of both seats with [SeatBoth](cartlib.md#constants). [SeatNone](cartlib.md#constants) does nothing, so a record's Physical can be passed straight through.

The host reads the strings in place, so passing a constant or an existing string allocates nothing; building one to pass (a `string(buf[:n])` conversion) allocates. For formatted text use [SetTextBytes](cartlib.md#func-settextbytes). LCD updates are meant for at most about 4 Hz (docs/CARTRIDGE.md rule 7), so throttle a readout driven by a per-tick value.

### func SetTextBytes

```go fragment

```

SetTextBytes is [SetText](cartlib.md#func-settext) taking the lines as bytes, so text formatted into a package-level buffer reaches the LCD without a string conversion:

```go fragment
var line [16]byte

n := copy(line[:], "SCORE ")
n += formatUint(line[n:], score) // the cartridge's own formatter
cartlib.SetTextBytes(seat, line[:n], nil)
```

The host copies the bytes before returning, so the buffers may be reused as soon as the call returns. Allocation-free.

### func StorageWrite

### type Attractor

### type ButtonMask

### type Channel

```go fragment
type Channel struct {
	// contains filtered or unexported fields
}
```

Channel is a bound input channel (docs/ASSETS.md, "Input channels"). An input record reports an event; a channel reports a current level, such as a held button, an axis position or a spinner's motion since the last Update.

Channels are bound through [Setup](cartlib.md#type-setup) in Init, the only phase in which the host hands out a handle. A failed bind, meaning nothing on this cabinet offers the channel, returns the zero Channel, whose Ok reports false and whose readers all return zero, so the game can check once and play differently:

```go fragment
func (g *myGame) Init(s *cartlib.Setup) {
    g.wheel = s.BindDelta(cartlib.P1 + "spinner")
}

func (g *myGame) Update(dtMicros uint64) {
    if g.wheel.Ok() {
        g.paddleX += g.wheel.Delta()
    } else {
        g.paddleX += g.dpadStep()
    }
}
```

Binding passes the name's own bytes and reading is one host call, so neither allocates.

#### func (Channel) Axis

```go fragment
func (c Channel) Axis() int
```

#### func (Channel) Blob

#### func (Channel) Button

```go fragment
func (c Channel) Button() bool
```

#### func (Channel) Delta

```go fragment
func (c Channel) Delta() int
```

Delta returns a delta channel's motion since the previous Update, or 0 for an unbound channel or one of another kind. The host samples once per tick, so repeated reads within a tick return the same value.

#### func (Channel) Ok

```go fragment
func (c Channel) Ok() bool
```

Ok reports whether the bind succeeded.

### type CheatCode

```go fragment
type CheatCode struct {
	// OnStep, if set, is called on each press that advances the sequence
	// except the completing one, with the new progress (1..CheatSteps-1),
	// so the cartridge can give entry feedback. Assign it in Init: a
	// package-level initializer that is not compile-time foldable never
	// runs.
	OnStep func(step int)
	// contains filtered or unexported fields
}
```

CheatCode detects the shared debug combo, hold Aux1 and push UP UP DOWN DOWN LEFT RIGHT LEFT RIGHT, in a stream of input records, so every cartridge's debug shortcut has the same entry. The zero value is ready. It keeps state across frames, so hold it in a package variable:

```text
var cheat cartlib.CheatCode

func handleRecord(r cartlib.InputRecord) {
    if seat, ok := cheat.Feed(r); ok {
        enterDebugMode(seat) // the physical seat, or SeatNone
        return
    }
    if !r.IsPress() {
        return
    }
    ...
}
```

Feed every record, ahead of any press-only filter, because the Aux1 hold is tracked from keydown and keyup records. Feed only in phases where the shortcut does something visible: a completed combo sets [CheatTainted](cartlib.md#func-cheattainted) whether or not the cartridge acts on it.

#### func (*CheatCode) Feed

```go fragment
func (c *CheatCode) Feed(r InputRecord) (Seat, bool)
```

Feed consumes one input record. It returns (seat, true) once, on the record that completes the combo, and (SeatNone, false) otherwise. seat is the physical seat of the player who entered it, or [SeatNone](cartlib.md#constants) for a source with no seat; every peripheral call ignores SeatNone, so it can be passed straight to [SetText](cartlib.md#func-settext) or [SetButtonLights](cartlib.md#func-setbuttonlights). After firing, the detector rearms on the next press.

Aux1 counts as held between its keydown and keyup. A source that reports only keypresses (the dev console keyboard) arms the combo with an Aux1 keypress instead, and the arming lasts until a wrong direction, any other keypress, or an Aux1 keyup. Feed uses no clock, so a replayed record stream reaches the same state.

#### func (*CheatCode) Progress

```go fragment
func (c *CheatCode) Progress() int
```

Progress returns how many steps of the sequence are matched, 0..CheatSteps-1.

#### func (*CheatCode) Reset

```go fragment
func (c *CheatCode) Reset()
```

Reset drops all progress, the remembered seat and the Aux1 state, keeping OnStep. Call it on a scene change that should not carry a half-entered combo across. It does not clear [CheatTainted](cartlib.md#func-cheattainted).

#### func (*CheatCode) Seat

```go fragment
func (c *CheatCode) Seat() Seat
```

Seat returns the physical seat of the player entering the combo, or [SeatNone](cartlib.md#constants) if no record with a real seat has been seen since the last fire or [CheatCode.Reset](cartlib.md#func-cheatcode-reset).

### type Framebuffer

```go fragment
type Framebuffer struct {
	// Pix is the pixel data, 4 bytes (R, G, B, A) per pixel, row-major.
	Pix [FBWidth * FBHeight * 4]byte

```

Framebuffer is a cartridge's local RGBA pixel buffer, sent whole to the host once per frame after Render (or Attract, or the splash) returns. Pix is row-major, interleaved R,G,B,A bytes per pixel, exactly host_blit's wire format.

The zero value is transparent black. cartlib owns the one Framebuffer every frame is drawn into and does not clear it between frames, so a gameplay frame should start with [Framebuffer.Clear](cartlib.md#func-framebuffer-clear); an attract frame may stay transparent where the engine's starfield should show.

#### func (*Framebuffer) Clear

```go fragment
func (fb *Framebuffer) Clear(r, g, b byte)
```

Clear fills the whole frame with one opaque color.

#### func (*Framebuffer) ClearTransparent

```go fragment
func (fb *Framebuffer) ClearTransparent()
```

#### func (*Framebuffer) FillRect

FillRect fills the rectangle [x, x+w) x [y, y+h), clipped to the frame, with one opaque color.

### type Game

```go fragment
type Game interface {
	// Init runs once, from cart_init, and is the first point at which
	// computed setup code runs: allocate everything the game will need
	// here, and load assets, bind channels and define glyphs through s,
	// the [Setup] that is live only until Init returns. The canvas is
	// always [FBWidth] by [FBHeight].
	Init(s *Setup)

	// HandleInput receives the tick's decoded input records
	// (docs/CARTRIDGE.md, "Input records"). Act on presses
	// ([InputRecord.IsPress]): a physical press arrives as a keydown and a
	// keypress, so acting on keydowns as well double-fires. Unless the Game
	// is a [QuitOwner], any quit-key press in the batch has already
	// requested [Exit]. records is reused on the next call; copy what must
	// outlive it.
	HandleInput(records []InputRecord)

	// Update advances the simulation by dtMicros, the microseconds since
	// the previous Update. dtMicros, or [NowMicros] on the same engine
	// clock, is the only source of time and [RandomU64] the only source of
	// randomness; a wall clock or OS RNG breaks replay determinism.
	Update(dtMicros uint64)

	// Render draws one frame into fb, which cartlib sends to the host when
	// Render returns; nothing else reaches the screen. fb keeps the previous
	// frame's pixels. Render may run before the first Update, so it must
	// draw a valid frame from the state Init left.
	Render(fb *Framebuffer)

	// Manifest returns the cart_manifest JSON (docs/CARTRIDGE.md,
	// "Manifest"): manifestBytes, the package-level slice manifest_gen.go
	// declares from a string constant. The SDK's manifestgen writes that
	// file from manifest.json on every build. Anything else, built at call
	// time or from runtime state, fails the post-build wasmfix pass:
	//
	//	func (g *myGame) Manifest() []byte { return manifestBytes }
	Manifest() []byte
}
```

Game is the interface a cartridge implements and registers with [Run](cartlib.md#func-run); cartlib's cart_* exports delegate to it.

The host calls [Game.Init](cartlib.md#type-game) once, then HandleInput, Update and Render in its frame loop, then [Teardowner.Teardown](cartlib.md#type-teardowner) if the Game is a [Teardowner](cartlib.md#type-teardowner). Manifest may be called at any point, before or after Init. All methods run on one thread; there are no goroutines.

### type GlyphRows

```go fragment
type GlyphRows = [8]byte
```

GlyphRows is one 5x8 LCD glyph: eight pixel rows, top to bottom. Only the low 5 bits of each row are used, and bit 4 is the leftmost column, so 0x10 lights the left pixel and 0x01 the right one; this is the HD44780 CGRAM encoding. A heart:

```go fragment
cartlib.GlyphRows{0x0, 0x0, 0xa, 0x1f, 0x1f, 0xe, 0x4, 0x0}
```

### type HostABI

```go fragment
	StorageWrite(key string, val []byte)

	NowMicros() uint64

	SetButtonLights(player int32, mask uint32, only int32)

	SetLights(player, on int32)

	DefineLcdGlyph(codepoint int32, rows uint64) uint32

	// Exit is host_exit: it requests the cartridge's unload, applied between ticks.
	Exit()

	// RejectKey is host_reject_key: it rings the "that key does nothing" bell, a no-op where there is none.
	RejectKey()

	// ScoreSubmit is host_score_submit: it records score and name in the top-10 table and returns the 1-based rank, or 0 if it did not place.
	ScoreSubmit(score int64, name string) uint32

	// ScoreRead is host_score_read: it writes the entry at 1-based rank into out (i64 little-endian score, then the name bytes) and returns the byte count, 0 past the end of the table.
	ScoreRead(rank uint32, out []byte) uint32

	// ScoreCount is host_score_count: it returns how many entries the table holds, 0 to 10.
	ScoreCount() uint32

	// ScoreQualifies is host_score_qualifies: it returns non-zero if score would place, by ScoreSubmit's rule.
	ScoreQualifies(score int64) uint32

	// ScoreRank is host_score_rank: it returns the 1-based rank score would take, or 0 if it would not place, writing nothing.
	ScoreRank(score int64) uint32

	// RecentNameGet is host_recent_name_get: it copies the name last noted for player (0 or 1) within the past hour into out and returns its length, 0 if none.
	RecentNameGet(player int32, out []byte) uint32

	// RecentNameAt is host_recent_name_at: it copies the index-th newest name of player's (0 or 1) history into out and returns its length, 0 past the end.
	RecentNameAt(player int32, index uint32, out []byte) uint32

	// RecentNameNote is host_recent_name_note: it records name as the one player (0 or 1) just confirmed; the host trims blanks and ignores an empty name.
	RecentNameNote(player int32, name string)

	// PushPlayerStrategy is host_push_player_strategy: it pushes the strategy of the given StrategyKind value.
	PushPlayerStrategy(kind uint32)

	// PopPlayerStrategy is host_pop_player_strategy: it removes the strategy this cartridge most recently pushed.
	PopPlayerStrategy()

	// LockPlayerStrategy is host_lock_player_strategy: it enforces the current strategy.
	LockPlayerStrategy()

	// UnlockPlayerStrategy is host_unlock_player_strategy: it relaxes the current strategy.
	UnlockPlayerStrategy()

	// SwitchPlayer is host_switch_player: it toggles or sets the turn by SwitchMode value; a no-op outside the two-player turn-based strategy.
	SwitchPlayer(mode uint32)

	// LockPlayerSeat is host_lock_player_seat: it locks the current one-player strategy to the physical seat 0 or 1; a no-op under any other strategy.
	LockPlayerSeat(physical int32)

	// SetRawDirections is host_set_raw_directions: a non-zero enabled turns the direction remap off for this instance, zero turns it on.
	SetRawDirections(enabled uint32)

	LoadSheet(path string) uint32

	SheetCel(sheet uint32, name string) uint32

	// CelInfo is host_cel_info: it writes the cel's four little-endian u16s (w, h, anchorX, anchorY) into out and returns non-zero, or 0 for a bad handle.
	CelInfo(cel uint32, out []byte) uint32

	// CelRead is host_cel_read: it copies the cel's straight-alpha RGBA into rgba and returns the byte count, which is w*h*4 on success and 0 on failure.
	CelRead(cel uint32, rgba []byte) uint32

	// InputBind is host_input_bind: it binds the named channel as the given channel kind (0 button, 1 axis, 2 delta, 3 blob) and returns its handle, or a negative value on failure.
	InputBind(name string, kind uint32) int32

	// InputButton is host_input_button: it returns non-zero while the bound button channel is held.
	InputButton(handle int32) uint32

	// InputAxis is host_input_axis: it returns the bound axis channel's position.
	InputAxis(handle int32) int32

	// InputDelta is host_input_delta: it returns the bound delta channel's motion since the previous update, the same value for every read within a tick.
	InputDelta(handle int32) int32

	// InputBlob is host_input_blob: it copies the bound blob channel into dst and returns the byte count, 0 if dst is shorter than the channel's declared length.
	InputBlob(handle int32, dst []byte) uint32

	// OutputBind is host_output_bind: it returns an output channel's handle, or a negative value on failure, which is every current host's answer.
	OutputBind(name string) int32

	// OutputSet is host_output_set: it drives the bound output channel.
	OutputSet(handle, value int32)

	// LightsPlay is host_lights_play: it starts the lamp sequence at path on seat (-1 for both) with the given LightsLoop value and returns non-zero if anything is now playing.
	LightsPlay(path string, seat int32, loop uint32) uint32

	// LightsStop is host_lights_stop: it stops the lamp sequence on seat (-1 for both), leaving the lamps at their levels.
	LightsStop(seat int32)

	// SetLampLevels is host_set_lamp_levels: it sets the lamps in touch on seat (-1 for both) to the packed levels (PackLampLevels), fading over fadeMs milliseconds.
	SetLampLevels(seat int32, levels, touch, fadeMs uint32)
```

HostABI is the cabinet's half of the ABI as Go values: one method per "arkade" import, with the import's wire types (a seat is the int32 the host receives, -1 for both) and Go slices and strings where the import takes a pointer and length. It exists under the plain Go toolchain only, where no wasm host is present: cartlib's wrappers call whatever [UseHost](cartlib.md#func-usehost) installed, so a cartridge's own `go test` can drive the Game against an in-process fake. sdk/cartlib/hosttest provides that fake; a cartridge test uses it rather than implementing HostABI itself.

Each method's contract is its import's, in docs/CARTRIDGE.md; the fake's job is to answer as the cabinet would.

#### func UseHost

```go fragment
func UseHost(h HostABI) (previous HostABI)
```

UseHost installs h as the host behind every cartlib call for the rest of the process, or until the next UseHost, and returns the host it replaced (nil at first). With none installed the first host call panics, so a test that reaches the host by accident fails loudly instead of reading zero. hosttest.New calls this and restores the previous host when the test ends.

### type Setup

```go fragment
type Setup struct {
	// contains filtered or unexported fields
}
```

Setup is the receiver for the calls only [Game.Init](cartlib.md#type-game) may make: loading sounds and sprite sheets, binding input and output channels, and defining LCD glyphs. Each one allocates in the guest, asks the host for a handle it hands out only during cart_init, or both, so none of them belongs in Update, HandleInput or Render, and the type system rather than a comment keeps them out: they are methods of Setup, cartlib passes the one live Setup to Init, and nothing else ever produces one.

```go fragment
func (g *myGame) Init(s *cartlib.Setup) {
    g.chime = s.LoadSound("assets/chime.wav")
    g.hero = s.LoadSheet("assets/hero.arkadesprite.png").Cel("idle")
    g.wheel = s.BindDelta(cartlib.P1 + "spinner")
}
```

The Setup is dead once Init returns. The zero Setup is dead too, so a cartridge cannot build a live one. A call through a dead Setup, or through a [Sheet](cartlib.md#type-sheet) it loaded, returns that call's failure value (0, the zero Sheet, a nil cel, an unbound Channel, false); under the plain Go toolchain it also panics, so a cartridge's `go test` and sdk/cartlib/hosttest catch the misuse, and on the cabinet it logs at [LogError](cartlib.md#type-loglevel), where the host's log and carttest's FakeHost.Logs show it. Keeping a *Setup in a field to use later is therefore a bug the tests find, not an escape hatch.

The canvas size is not a Setup concern: it is [FBWidth](cartlib.md#constants) by [FBHeight](cartlib.md#constants), constants, which is why Init takes no cols and rows.

#### func (*Setup) DefineLCDGlyph

```go fragment
func (s *Setup) DefineLCDGlyph(r rune, rows GlyphRows) bool
```

DefineLCDGlyph makes the cabinet's LCDs draw r as rows while this cartridge is loaded, overriding the engine's built-in glyph for r if there is one. Definitions end when the cartridge unloads.

It reports whether the definition was accepted, with the same answer on every host, including one with no LCD. It returns false when:

- r is below U+0080: the LCD's ROM draws ASCII.
- r is an emoji or East Asian wide rune: U+1F000 to U+1FFFF, the emoji-presentation symbols, variation selectors, the zero-width joiner, CJK, Hangul, kana, the fullwidth forms, and everything from U+20000 up. A glyph rune must be a plain single-width monochrome character; ♥, ☺, ✔, arrows, shades and the private-use area are fine.
- r is not a code point: a surrogate, a noncharacter, or past U+10FFFF.
- [MaxCartGlyphs](cartlib.md#constants) distinct runes are already defined. Redefining a rune always succeeds.

Each LCD can show at most eight distinct custom glyphs at once, built-in ones included; a ninth on the same screen draws as '?'.

#### func (*Setup) LoadSheet

```go fragment
func (s *Setup) LoadSheet(path string) Sheet
```

LoadSheet loads the sprite sheet at a bundle-relative path such as "assets/hero.arkadesprite.png" (docs/ASSETS.md, "Sprites from the bundle"). Nothing is copied into the guest until [Sheet.Cel](cartlib.md#func-sheet-cel). A failed load, including a bare .wasm build with no bundle, returns the zero [Sheet](cartlib.md#type-sheet), whose Cel returns nil, and the host logs why.

**Example**

```go
package cartlib_test

import (
	"fmt"
	"testing"

	"github.com/stealthmonkey99/arkade/sdk/cartlib"
	"github.com/stealthmonkey99/arkade/sdk/cartlib/hosttest"
)

// loadSheetTB stands in for the *testing.T a real test passes to hosttest.New.
type loadSheetTB struct {
	testing.TB
	cleanups []func()
}

func (e *loadSheetTB) Helper()          {}
func (e *loadSheetTB) Cleanup(f func()) { e.cleanups = append(e.cleanups, f) }

type loadSheetGame struct {
	hero, missing cartlib.Sheet
}

var loadSheetManifest = []byte(`{"abi":1,"slug":"hero","name":"hero"}`)

func (g *loadSheetGame) Manifest() []byte { return loadSheetManifest }

func (g *loadSheetGame) HandleInput(records []cartlib.InputRecord) {}

func (g *loadSheetGame) Init(s *cartlib.Setup) {
	g.hero = s.LoadSheet("assets/hero.arkadesprite.png")
	g.missing = s.LoadSheet("assets/nothing.arkadesprite.png")
}

func (g *loadSheetGame) Update(dtMicros uint64) {}

func (g *loadSheetGame) Render(fb *cartlib.Framebuffer) { fb.Clear(0, 0, 0) }

func ExampleSetup_LoadSheet() {
	tb := &loadSheetTB{}
	defer func() {
		for _, f := range tb.cleanups {
			f()
		}
	}()

	h := hosttest.New(tb) // in a test: hosttest.New(t)
	h.AddCel("assets/hero.arkadesprite.png", "idle", 2, 2, make([]byte, 2*2*4))

	g := &loadSheetGame{}
	h.Init(g)

	fmt.Println("hero loaded:", g.hero.Ok())
	fmt.Println("missing loaded:", g.missing.Ok())
}
```

```text

missing loaded: false
```

### type Sheet

```go fragment
type Sheet struct {
	// contains filtered or unexported fields
}
```

Sheet is a handle on one sprite sheet loaded by [Setup.LoadSheet](cartlib.md#func-setup-loadsheet) (docs/ASSETS.md, "Sprites from the bundle"). The zero Sheet is the failed-load value: its Cel returns nil, so a cartridge can lift cels without checking first.

Lifting a cel allocates, under a collector that never frees, so a Sheet is as Init-only as the Setup that loaded it: lift every cel the game will draw in [Game.Init](cartlib.md#type-game), keep the sprites, and never call Cel again. Each cel's collision mask is [ui.OpaqueMask](ui.md#func-opaquemask)'s: exactly the A==255 pixels.

#### func (Sheet) Cel

```go fragment
func (s Sheet) Cel(name string) *ui.Sprite
```

Cel copies the named cel into a new [ui.Sprite](ui.md#type-sprite) whose collision mask is its pixels with alpha 255; lower alpha draws blended but never collides. It returns nil when the sheet did not load, has no cel by that name, or the cel exceeds 64 pixels on a side. Each call allocates the pixels, the mask and the sprite, so Cel is live only while the [Setup](cartlib.md#type-setup) that loaded the sheet is: after Init it returns nil and fails as a stale Setup call does.

**Example**
